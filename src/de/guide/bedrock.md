# Minecraft Bedrock Edition Anleitung

Der XMCL unterstützt das Verwalten, Herunterladen und Starten von **Minecraft Bedrock Edition** (auch bekannt als *Windows 10/11 Edition* oder *UWP Edition*).

---

## 1. Systemanforderungen & Einrichtung (Nur Windows)

### Schritt 1: Windows-Entwicklermodus aktivieren
1. Öffnen Sie die **Windows-Einstellungen** (`Win + I`).
2. Gehen Sie zu **Datenschutz & Sicherheit** -> **Für Entwickler**.
3. Aktivieren Sie den **Entwicklermodus**.

---

## 2. Paketherkunft & Offizielle Server

- **Versionsdatenbank (`mrarm.io/r/w10-vdb`)**: Bietet die Liste der offiziellen Versions-GUIDs.
- **Downloads (`tlu.dl.delivery.mp.microsoft.com`)**: Das Paket (`.appx`) wird direkt vom **offiziellen Microsoft Windows Update CDN** heruntergeladen.

---

## 3. Betriebssystem-Kompatibilität

| Betriebssystem | Status | Details |
| :--- | :--- | :--- |
| 💻 **Windows 10 / 11** | ✅ **Voll unterstützt** | Native UWP-Umgebung. |
| 🍎 **macOS** | ❌ **Nicht unterstützt** | Nutzt Windows-spezifische UWP APIs. Nutzen Sie **Java Edition**. |
| 🐧 **Linux** | ❌ **Nicht unterstützt** | Nutzt Windows-spezifische UWP APIs. Nutzen Sie **Java Edition**. |
