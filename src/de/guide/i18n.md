## Editor-Einrichtung

::: code-group
```markdown [VS Code]
Installieren Sie die Erweiterung **i18n Ally** (`lokalise.i18n-ally`).
```

```sh [Zed Editor]
1. Installieren Sie die Erweiterungen `YAML` und `Vue`.
2. Öffnen Sie `en.yaml` und Ihre Zielsprache nebeneinander (`Cmd+Shift+E` / `Ctrl+Shift+E` -> Split Right).
```

```vim [Neovim]
:e xmcl-keystone-ui/locales/en.yaml
:vsplit xmcl-keystone-ui/locales/de.yaml
:set scrollbind
```
