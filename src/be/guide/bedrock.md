# Гайд па Minecraft Bedrock Edition

XMCL падтрымлівае кіраванне, загрузку і запуск **Minecraft Bedrock Edition** (*Windows 10/11 Edition* / *UWP Edition*).

---

## 1. Сістэмныя патрабаванні (Толькі Windows)

### Уключыце Рэжым распрацоўшчыка Windows
1. Адкрыйце **Наладкі Windows** (`Win + I`).
2. Перайдзіце ў **Прыватнасць і бяспека** -> **Для распрацоўшчыкаў**.
3. Уключыце **Рэжым распрацоўшчыка**.

---

## 2. Адкуль бяруцца пакеты?

Пакеты (`.appx`) спампоўваюцца напрамую з **афіцыйнага CDN абнаўленняў Microsoft (Windows Update Delivery)**.

---

## 3. Сумяшчальнасць з АС

| Аперацыйная сістэма | Стан | Дэталi |
| :--- | :--- | :--- |
| 💻 **Windows 10 / 11** | ✅ **Поўная падтрымка** | Натыўнае UWP асяроддзе. |
| 🍎 **macOS** | ❌ **Не падтрымліваецца** | Патрабуе Windows UWP API. Гуляйце ў **Java Edition**. |
| 🐧 **Linux** | ❌ **Не падтрымліваецца** | Патрабуе Windows UWP API. Гуляйце ў **Java Edition**. |
