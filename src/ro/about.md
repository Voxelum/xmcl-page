Dacă ai `winget`, îl poți folosi pentru instalare:

```bash
winget install CI010.XMinecraftLauncher
```

Instalarea prin Homebrew este de asemenea disponibilă via tap:

```bash
brew tap voxelum/xmcl
brew install --cask --no-quarantine voxelum/xmcl
```
