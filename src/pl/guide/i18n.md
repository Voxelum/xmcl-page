# Przewodnik po lokalizacji i tłumaczeniu

Dziękujemy za pomoc w tłumaczeniu X Minecraft Launcher (XMCL)!

---

## Konfiguracja edytorów

::: code-group
```markdown [VS Code]
Zainstaluj rozszerzenie **i18n Ally** (`lokalise.i18n-ally`).
```

```sh [Zed Editor]
1. Zainstaluj rozszerzenia `YAML` i `Vue`.
2. Otwórz `en.yaml` i swój język obok siebie (`Ctrl+Shift+E` -> Split Right).
```

```vim [Neovim]
:e xmcl-keystone-ui/locales/en.yaml
:vsplit xmcl-keystone-ui/locales/pl.yaml
:set scrollbind
```
:::
