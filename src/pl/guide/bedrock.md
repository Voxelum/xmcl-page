# Przewodnik по Minecraft Bedrock Edition

X Minecraft Launcher (XMCL) obsługuje zarządzanie, pobieranie i uruchamianie **Minecraft Bedrock Edition** (*Windows 10/11 Edition* / *UWP Edition*).

---

## 1. Wymagania systemowe (Tylko Windows)

### Włącz Tryb Dewelopera Windows
1. Otwórz **Ustawienia Windows** (`Win + I`).
2. Przejdź do **Prywatność i bezpieczeństwo** -> **Dla deweloperów**.
3. Włącz **Tryb dewelopera**.

---

## 2. Skąd pochodzą pakiety Bedrock?

Pakiety (`.appx`) są pobierane bezpośrednio z **oficjalnego serwera CDN Microsoft (Windows Update Delivery)**.

---

## 3. Kompatybilność systemów operacyjnych

| System operacyjny | Status | Szczegóły |
| :--- | :--- | :--- |
| 💻 **Windows 10 / 11** | ✅ **Pełne wsparcie** | Natywne środowisko UWP. |
| 🍎 **macOS** | ❌ **Brak wsparcia** | Wymaga API Windows UWP. Graj w **Java Edition**. |
| 🐧 **Linux** | ❌ **Brak wsparcia** | Wymaga API Windows UWP. Graj w **Java Edition**. |
