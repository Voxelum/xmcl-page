XMCL оснащений повноцінним режимом **Big Picture** — спеціальним повноекранним інтерфейсом, оптимізованим для диванного геймінгу на телевізорі, гри з геймпада на ПК та портативних консолях (Steam Deck, ROG Ally, Lenovo Legion Go тощо).

---

Підтримувані геймпади та контролери

XMCL має глибоку вбудовану систему розпізнавання контролерів на базі W3C Gamepad API та адаптує інтерфейс під кожен пристрій індивідуально:

| Тип контролера | Моделі та пристрої | Підказки кнопок |
| :--- | :--- | :--- |
| **Steam Deck** | Вбудований контролер Valve Steam Deck (Neptune), Gamescope, SteamOS Game Mode | `A`, `B`, `X`, `Y`, `L1/R1`, `L2/R2`, `View`, `Menu` |
| **Xbox** | Xbox Series X/S, Xbox One, Xbox 360, Xbox Elite Controller, а також будь-які сторонні XInput-контролери | `A`, `B`, `X`, `Y`, `LB/RB`, `LT/RT`, `View`, `Menu` |
| **PlayStation** | DualSense (PS5), DualSense Edge, DualShock 4 (PS4), DualShock 3 (PS3), PS2 через USB-адаптери | `` (Хрестик), `○` (Коло), `□` (Квадрат), `△` (Трикутник), `L1/R1`, `L2/R2`, `Share/Options` |
| **Nintendo Switch** | Nintendo Switch Pro Controller, Joy-Con (як пара або окремо) | `B` (Підтвердити), `A` (Скасувати), `Y`, `X`, `L/R`, `ZL/ZR`, `-`, `+` |
| **Nintendo Wii / Wii U** | Nintendo Wii Remote (Wiimote через Bluetooth/Dolphin), Wii U Pro Controller | `A`, `B`, `1`, `2`, `L/R`, `ZL/ZR`, `-`, `+` |
| **Універсальні геймпади** | Будь-які Bluetooth або USB-контролери зі стандартною розкладкою DirectInput/HID | Стандартні кнопки за W3C індексами |

::: tip Адаптивний інтерфейс підказок
Під час підключення геймпада XMCL автоматично визначає тип пристрою та змінює піктограми на екрані. Наприклад, якщо підключено геймпад PlayStation, інтерфейс показуватиме фірмові символи `` та `○`, а для Xbox чи Steam Deck — відповідні літери `A`, `B`, `X`, `Y`.
:::

Керування в режимі Big Picture

Режим Big Picture повністю виключає необхідність використовувати клавіатуру чи мишу. Ви можете керувати лаунчером лише за допомогою кнопок геймпада:

* **Лівий стік / D-Pad (Хрестовина)**: плавне просторове переміщення між елементами інтерфейсу, картками інстансів та кнопками меню.
* **Нижня кнопка (`A` / `` / `B`)**: підтвердження вибору, запуск гри, відкриття налаштувань.
* **Права кнопка (`B` / `○` / `A`)**: повернення назад, закриття модальних вікон або скасування дій.
* **Бампери (`L1/R1` або `LB/RB`)**: швидке горизонтальне перемикання між основними розділами лаунчера (Головна, Каталог збірок, Налаштування, Логи).
* **Тригери (`L2/R2` або `LT/RT`)**: перегортання сторінок списку при пошуку модів, модпаків та ресурсів у вбудованому каталозі CurseForge та Modrinth.
* **Верхня кнопка (`Y` / `△`)**: відкриття пошуку та виклик віртуальної клавіатури.

---

## ⌨ Вбудована віртуальна клавіатура

Для введення назв збірок, пошуку модифікацій чи введення параметрів у Big Picture не потрібна фізична клавіатура. 

1. Натисніть кнопку вибору текстового поля або скористайтеся кнопкою `Y` (`△`).
2. На екрані з'явиться віртуальна клавіатура, адаптована для швидкого вибору символів стіком або D-Pad.
3. Кнопка `X` (`□`) слугує для швидкого видалення символів (Backspace).
4. Кнопка `A` (``) вводить виділений символ, а кнопка `Start / Menu` підтверджує введення.

Налаштування авто-запуску та параметрів

Ви можете налаштувати, як саме лаунчер поводиться з контролерами:

1. Відкрийте **Налаштування (Settings)** -> **Загальні (General)**.
2. Знайдіть блок параметрів **Big Picture**:
   - **Запуск у режимі Big Picture за замовчуванням (`Default Launch`)**: лаунчер завжди стартуватиме у повноекранному інтерфейсі Big Picture.
   - **Автоматичний перехід при підключенні геймпада (`Auto on Gamepad`)**: якщо лаунчер запущено у звичайному режимі, при підключенні фізичного геймпада або натисканні будь-якої кнопки на ньому XMCL автоматично перемкнеться в Big Picture.

Використання на Steam Deck та SteamOS

XMCL офіційно підтримує роботу на **Steam Deck**:

* **Автоматичне розпізнавання консольного режиму**: при запуску через інтерфейс **SteamOS Game Mode** (Gamescope) лаунчер автоматично розпізнає портативне середовище та запускається в оптимізованому повноекранному форматі 1280x800.
* **Швидкий вихід**: у бічному меню передбачено кнопку виходу назад на робочий стіл чи повернення у клієнт Steam.
* **Повна підтримка тачпаду та гіроскопа**: завдяки інтеграції зі Steam Input ви можете користуватися як апаратними кнопками геймпада, так і трекпадами для емуляції миші.
