# Руководство по установке

Лаунчер XMCL поддерживает различные варианты установки в зависимости от используемой операционной системы. Ниже описаны поддерживаемые форматы и их особенности.

---

## Windows

:::info Рекомендация
Для Windows рекомендуется использовать классический установщик, портативную версию или пакет `appinstaller`.
:::

### Классический установщик и AppX
- **APPX / MSIX**: Запускается в изолированной песочнице Windows. Кэш, временные файлы и ассоциации хранятся изолированно от системного реестра.
- **Портативная версия (ZIP)**: Не требует установки с правами администратора, подходит для запуска с внешних дисков.

### Windows 7 / 8
По умолчанию XMCL ориентирован на современные версии Windows 10/11. Для пользователей устаревших систем доступен обходной путь через расширенное ядро [VxKex-NEXT](https://github.com/YuZhouRen86/VxKex-NEXT):
1. Установите ядро VxKex-NEXT.
2. В свойствах `XMCL.exe` включите опции «Включить VxKex NEXT для этой программы» и «Сообщать о других версиях Windows».

## macOS

Пакет для macOS распространяется в формате DMG:
1. Скачайте образ DMG со страницы релизов.
2. Откройте образ и перетащите `XMCL.app` в системную папку `Applications` (`Программы`).
3. При первом запуске ввиду отсутствия платной подписи Apple Gatekeeper может заблокировать запуск. Для снятия блокировки выполните в терминале:
   ```sh
   sudo xattr -cr /Applications/XMCL.app
   ```

## Linux

Для систем Linux XMCL ориентирован на поддержку современных универсальных пакетов (пакет Snap отсутствует, а поддержка AUR для Arch Linux прекращена в пользу официального Flatpak):

### 1. Flatpak (Flathub) — Рекомендуется
- Официальный рекомендуемый способ установки для **Arch Linux**, **Fedora**, **Ubuntu**, **Debian** и **Steam Deck (SteamOS)**.
- Обеспечивает полную изоляцию, безопасность и автоматические обновления через Flathub:
  ```sh
  flatpak install flathub app.xmcl.XMCL
  ```

### 2. AppImage — Универсальный автономный файл
- Единый исполняемый файл, запускающийся на любом дистрибутиве Linux без установки:
  ```sh
  chmod +x xmcl-*.AppImage
  ./xmcl-*.AppImage
  ```
- Отлично подходит для запуска в режиме рабочего стола Steam Deck.

### 3. Автономный Tarball (.tar.xz) и бинарные пакеты
- На странице релизов доступны архивы `.tar.xz`, а также пакеты `.deb` (Debian/Ubuntu) и `.rpm` (Fedora/openSUSE).

## Выбор каталога игровых данных

Во время начальной установки необходимо указать директорию `Game Data Directory`. В этот каталог XMCL поместит загруженные ассеты, библиотеки и версии Minecraft.

:::warning
Из-за специфики изоляции инстансов не рекомендуется использовать стандартный путь `.minecraft` в качестве корневого каталога XMCL. Рекомендуется создать отдельную чистую папку.
:::
