# Руководство по обновлению

Это руководство описывает способы обновления XMCL на Windows, macOS и Linux, а также объясняет, как гарантировать полную сохранность игровых инстансов, сохранений миров и аккаунтов.

:::tip Гарантия безопасности данных
Обновление XMCL **никогда не удаляет ваши инстансы, моды, миры или учетные записи**. Все данные пользователя хранятся отдельно от исполняемых файлов лаунчера в системных каталогах.
:::

---

## Windows

### 1. Встроенное автоматическое обновление (Стандартный способ)
1. При выходе нового релиза в верхней панели заголовка окна появляется значок обновления.
2. Нажмите на уведомление, чтобы просмотреть список изменений и начать фоновую загрузку.
3. По завершении нажмите **Перезапустить и обновить**. Лаунчер перезапустится в новой версии.

### 2. Пакеты AppInstaller и APPX
- Если XMCL был установлен через пакет `xmcl.appinstaller`, операционная система Windows автоматически проверяет и загружает обновления при запуске через службу Windows Delivery Optimization.
- Скачиваются только измененные бинарные блоки (инкрементные обновления), что существенно экономит трафик.
- Если автообновление завершилось сбоем, скачайте свежий файл `xmcl.appinstaller` с официального сайта и запустите его вручную для восстановления.

### 3. Портативный архив (Portable ZIP) и DeskGap
- **Portable ZIP**: Скачайте свежий архив `xmcl-*-win32-x64.zip` со страницы релизов, распакуйте его и замените старые файлы. Все ваши миры и настройки сохранятся, так как они находятся в `%AppData%\xmcl`.
- **DeskGap (v0.72.0+)**: Распакуйте новый архив `xmcl-*-deskgap-win32-x64.zip` поверх текущей папки.

## macOS

### 1. Автоматическое обновление в приложении
- Лаунчер самостоятельно проверяет официальный канал релизов для macOS.
- При появлении новой версии загрузка и перезапуск выполняются в один клик.

### 2. Обновление через файл DMG
1. Скачайте свежий `.dmg` для процессора вашего Mac:
   - **Apple Silicon (M1 / M2 / M3 / M4)**: `arm64.dmg`
   - **Процессоры Intel**: `x64.dmg`
2. Откройте файл `.dmg`.
3. Перетащите **XMCL.app** в папку **Программы (Applications)** и выберите **Заменить (Replace)**.

:::warning Снятие карантина Gatekeeper
Если macOS блокирует обновленную программу предупреждением о поврежденном файле или неизвестном разработчике, выполните следующую команду в **Terminal**:

```sh
sudo xattr -cr /Applications/XMCL.app
```
:::

## Linux и Steam Deck

### 1. AppImage
- **Прямая замена файла**: Скачайте свежий `xmcl-*.AppImage`, дайте ему права на исполнение и запустите:
  ```sh
  chmod +x xmcl-*.AppImage
  ./xmcl-*.AppImage
  ```
- **AppImageUpdate**: Если вы используете утилиты автоматизации, лаунчер поддерживает бинарное дельта-обновление через `appimageupdatetool`.
- **Steam Deck**: В режиме рабочего стола SteamOS Desktop Mode просто замените существующий файл `xmcl.AppImage` в вашей папке `Applications` или `Games`.

### 2. Flatpak (Flathub) — Рекомендуется
Flatpak является официально поддерживаемым основным форматом для Linux (включая Arch Linux, Fedora, Ubuntu и SteamOS). Обновите его через системный центр приложений или командой в консоли:

```sh
flatpak update app.xmcl.XMCL
```

### 3. Автономные архивы и бинарные пакеты
Для пакетов `.tar.xz`, `.deb` или `.rpm` скачайте последнюю версию со страницы релизов и установите поверх текущей.

## Резервное копирование и пути к данным

Если перед обновлением вы хотите сделать резервную копию вручную, ваши данные хранятся в следующих каталогах:

::: code-group
```cmd [Windows]
%AppData%\xmcl
```
```sh [macOS]
~/Library/Application Support/xmcl
```
```sh [Linux]
~/.config/xmcl
```
:::

Достаточно скопировать эту папку на внешний диск или в облако, чтобы получить полный бекап всех инстансов, аккаунтов и настроек.
