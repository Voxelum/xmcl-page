# Уведомление о конфиденциальности открытого проекта XMCL

**Дата вступления в силу: 22 ноября 2026 г. · Версия: OP3-2026-11-22**

Настоящее уведомление распространяется на публичный веб-сайт XMCL ([xmcl.app](https://xmcl.app)) и бесплатный лаунчер XMCL с открытым исходным кодом. Оно не распространяется на платные функции, учетные записи, биллинг, функции ИИ или сервисы сигнализации/TURN для мультиплеера, предоставляемые платным сервисом XMCL Together, которые регулируются отдельной [Политикой конфиденциальности XMCL Together](./together/privacy).

## 2. Обрабатываемая информация и минимизация данных

XMCL придерживается строгих принципов минимизации данных:

### Публичный веб-сайт (xmcl.app)
- **Агрегированная аналитика без файлов cookie:** мы используем Microsoft Azure Application Insights в **режиме без файлов cookie** (`disableCookiesUsage: true`) с точкой приема данных в **Microsoft Azure East Asia (Гонконг)** для учета анонимных просмотров страниц, выбора загрузок, общих параметров сети/устройства и заголовков User-Agent браузера. Аналитические или межсайтовые файлы cookie для отслеживания на ваше устройство не устанавливаются.
- **Строго необходимый файл cookie:** мы сохраняем только один локальный функциональный файл cookie (`nf_lang`), строго необходимый для запоминания выбранного языка интерфейса. Мы не используем сторонние маркетинговые, рекламные или поведенческие файлы cookie.

### Лаунчер с открытым исходным кодом
- **Добровольная телеметрия и диагностика (Opt-in):** диагностическая телеметрия **отключена по умолчанию**. Только если вы явно включите телеметрию в настройках лаунчера (Opt-in), лаунчер может обрабатывать:
  - случайно сгенерированный псевдонимный идентификатор установки/устройства;
  - события жизненного цикла приложения (запуск игры, коды нормального завершения или ошибок, версию приложения);
  - тип провайдера аутентификации (например, идентификатор Microsoft или офлайн-режима);
  - базовые параметры среды выполнения (операционную систему, версию Java, архитектуру процессора);
  - журналы сбоев и трассировки стека ошибок.
- **Очистка данных и учетные данные:** журналы сбоев по возможности очищаются от конфиденциальных путей к файлам, имен пользователей и системных токенов. Мы **никогда** не обрабатываем и не храним пароли, учетные данные или токены сессий ваших аккаунтов Microsoft/Mojang.

## 3. Сроки хранения данных

Мы не храним данные бессрочно:
- Все журналы телеметрии, записи диагностики ошибок и метрики производительности хранятся **не более 90 дней**, после чего безвозвратно удаляются или необратимо обезличиваются.
- Публичные обращения в трекере проблем на GitHub сохраняются в соответствии с политиками платформы GitHub и правилами ведения репозитория до их разрешения или удаления.

| Провайдер | Роль и категории данных | Регионы обработки | Политика конфиденциальности |
| :--- | :--- | :--- | :--- |
