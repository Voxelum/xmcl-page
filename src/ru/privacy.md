# Уведомление о конфиденциальности открытого проекта XMCL

**Дата вступления в силу: 14 августа 2026 г. · Версия: OP1-2026-08-14**

Это уведомление относится к публичному сайту XMCL и бесплатному лаунчеру с открытым исходным кодом. Оно не распространяется на учетные записи, платежи, ИИ, сигналинг, TURN и другие дополнительные сервисы XMCL Together; для них действует [Политика конфиденциальности XMCL Together](./together/privacy).

Сайт использует Microsoft Azure Application Insights для сбора сведений о просмотрах, выборе загрузок, приблизительных параметрах сети и устройства, браузере и диагностических событиях. Также сохраняется cookie с языковыми настройками.

Лаунчер может отправлять случайный идентификатор установки или устройства, события запуска и завершения игры, сведения о сервисе входа, параметры запуска, коды завершения, версию приложения, данные операционной системы и неожиданные ошибки со стеком. Диагностика иногда может содержать пути к файлам, имена сборок и пользователей, адреса серверов или значения из конфигурации.

Эти сведения используются для доставки загрузок, диагностики, безопасности и улучшения XMCL. Их могут обрабатывать Microsoft Azure, Vercel, GitHub и сопровождающие проекта, которым нужен доступ для поддержки, надежности или безопасности. Мы не продаем персональные данные и не используем телеметрию лаунчера для межконтекстной поведенческой рекламы.

Отключайте необязательную телеметрию там, где доступна соответствующая настройка, и проверяйте журналы перед публикацией. По вопросам доступа, исправления или удаления допустимых непубличных данных обращайтесь к CI010: **cijhn@hotmail.com**. XMCL не предназначен для детей младше 13 лет.

XMCL — независимый проект с открытым исходным кодом, не связанный с Microsoft или Mojang Studios и не одобренный ими.
