# إشعار الخصوصية لمشروع XMCL مفتوح المصدر

**تاريخ السريان: 21 أغسطس 2026 · الإصدار: OP2-2026-08-21**

يسري هذا الإشعار على الموقع الإلكتروني العام لـ XMCL ([xmcl.app](https://xmcl.app)) وعلى مشغل XMCL المجاني ومفتوح المصدر. ولا يسري هذا الإشعار على الحسابات أو المدفوعات أو الذكاء الاصطناعي أو خدمات خوادم اللعب الجماعي/TURN التابعة لـ XMCL Together، والتي تخضع بشكل منفصل لـ [سياسة خصوصية XMCL Together](./together/privacy).

## 2. البيانات المعالجة ومبدأ الحد الأدنى

يلتزم المشروع بالحد الأدنى من جمع البيانات ومعالجة المعلومات الفنية فقط:

### الموقع الإلكتروني (xmcl.app)
- **تحليلات مجمعة:** نستخدم Microsoft Azure Application Insights لتسجيل المشاهدات المجهولة، وتحديد اختيارات التنزيل، ونوع المتصفح ونظام التشغيل.
- **ملفات تعريف الارتباط (Cookies):** نستخدم فقط ملف تعريف ارتباط فني محلي لحفظ لغة العرض المفضلة لديك. لا نستخدم أي ملفات تعريف ارتباط إعلانية أو تتبعية لأطراف ثالثة.

### المشغل مفتوح المصدر (Launcher)
- **القياس عن بُعد والتشخيص بموافقة صريحة (Opt-in):** خدمة جمع التشخيص معطلة **افتراضياً**. فقط إذا قمت بتفعيلها يدوياً وصراحة في إعدادات المشغل، يتم جمع:
  - معرّف عشوائي مستعار للجهاز/التثبيت لا يحدد هوية الشخص الحقيقية؛
  - سجلات بدء اللعبة وإنهائها ورموز الخروج؛
  - مواصفات بيئة التشغيل (نظام التشغيل، إصدار Java، بنية المعالج)؛
  - تقارير الأخطاء والانهيارات (Stack Traces) مع تصفية المسارات المحلية الحساسة تلقائياً.
- **أمان الحسابات:** نحن **لا** نجمع أو نخزن أو نصل إلى كلمات مرور حسابات Microsoft أو Mojang أو رموز الوصول الخاصة بك أبداً.

## 3. مدة الاحتفاظ بالبيانات

نحدد بوضوح مدد الاحتفاظ بالبيانات الفنية:
- يتم الاحتفاظ بسجلات التشخيص والقياس عن بُعد لمدة **أقصاها 90 يوماً**، وبعدها يتم حذفها نهائياً أو إخفاء هويتها بشكل لا رجعة فيه.
- البلاغات والمشاركات العامة في GitHub Issues تخضع لسياسات منصة GitHub وإدارة المشروع.

---

## 4. نقل البيانات عبر الحدود

- يستخدم المشروع مزودي بنية تحتية سحابية دوليين موثوقين (Microsoft Azure وCloudflare وGitHub وVercel).
- **الضمانات:** يتم نقل البيانات الفنية خارج بلد الإقامة بموجب موافقتك الصريحة ومع تطبيق ضمانات تعاقدية ومعايير حماية ملائمة تضمن الحفاظ على خصوصية البيانات وأمنها بما يتوافق مع الأنظمة المعمول بها (مثل نظام حماية البيانات الشخصية السعودي والإماراتي).
- **عدم البيع:** نحن لا نبيع البيانات الشخصية مطلقاً ولا نشاركها لأغراض الإعلانات السلوكية.

---

## 5. السن القانوني وحماية القاصرين

- يجب أن يكون المستخدم قد بلغ السن القانوني لتقديم الموافقة المستنيرة وفقاً لأنظمة بلده (15-18 عاماً، أو السن الرقمي المحدد في دولة إقامتهم).
- بالنسبة للقاصرين دون هذا السن، يلزم الحصول على **موافقة صريحة من ولي الأمر أو الوصي الشرعي**.
- لا يجمع المشروع بيانات الأطفال عمداً دون موافقة قانونية.

---

## 6. حقوق صاحب البيانات

وفقاً لأنظمة حماية البيانات الشخصية المعمول بها، يحق لك:
1. العلم والمعرفة ببياناتك والغرض من معالجتها؛
2. الوصول إلى بياناتك الشخصية المتاحة وطلب نسخة منها؛
3. طلب تصحيح أو تحديث البيانات؛
4. طلب إتلاف أو مسح بياناتك («حق المحو»)؛
5. الرجوع عن الموافقة في أي وقت (بإلغاء تفعيل القياس في إعدادات المشغل).
