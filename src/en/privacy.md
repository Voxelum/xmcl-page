# XMCL Open-Source Project Privacy Notice

**Effective date: August 14, 2026 · Version: OP1-2026-08-14**

This notice covers the public XMCL website and the free, open-source launcher. It does not cover XMCL Together accounts, billing, AI, signaling, TURN, or other optional hosted services, which are covered by the [XMCL Together Privacy Policy](./together/privacy).

## Information processed

The website uses Microsoft Azure Application Insights to record page views, download selections, approximate network and device information, browser information, and diagnostic events. It also stores a language-preference cookie.

The launcher may send a randomly generated installation or device identifier, game start and exit events, login events, login-service name, launch arguments, game exit codes, application version, operating-system information, and unexpected errors with stack traces. Diagnostic fields can sometimes contain file paths, instance names, usernames, server addresses, or values present in an error or launch configuration.

Support requests and public issue reports contain the information you choose to submit. Review logs before sharing them and do not publish passwords, access tokens, payment data, or unrelated personal information.

## Purpose and sharing

This information is used to deliver downloads, understand reliability, diagnose failures, secure project infrastructure, and improve XMCL. It may be processed by Microsoft Azure, Vercel, GitHub, and maintainers who need it for support, reliability, or security work. We do not sell personal information or use launcher telemetry for cross-context behavioral advertising.

## Choices, retention, and contact

You can avoid optional telemetry where the launcher provides a setting, block website cookies or scripts in your browser, and remove sensitive fields before filing an issue. Telemetry and diagnostics are retained on rolling schedules appropriate to reliability and security; public GitHub content remains subject to GitHub controls and project moderation.

For access, correction, or deletion requests concerning eligible non-public project data, contact CI010 at **cijhn@hotmail.com**. XMCL is not directed to children under 13.

XMCL is an independent open-source project and is not affiliated with or endorsed by Microsoft or Mojang Studios.
