## 2. 处理的信息与最小化原则

XMCL 严格遵循数据最小化原则：

### 公开网站（xmcl.app）
- **无 Cookie 聚合分析：** 我们使用配置为**无 Cookie 模式**（`disableCookiesUsage: true`）且数据接入位于 **Microsoft Azure 东亚（中国香港）** 区域的 Microsoft Azure Application Insights，用于记录匿名页面浏览量、下载选项、常规网络/设备属性及浏览器 User-Agent。我们不会在您的设备上放置任何分析类或跨站追踪类 Cookie。
- **严格必要 Cookie：** 我们仅在本地存储一个严格必要的功能性 Cookie（`nf_lang`），用于记住您的界面语言偏好。我们不使用任何第三方营销、广告或行为追踪 Cookie。

### 开源启动器
- **选择加入（Opt-in）的遥测与诊断：** 诊断遥测功能**默认关闭**。仅在您在启动器设置中明确开启遥测（选择加入）后，启动器才会处理以下信息：
  - 随机生成的假名化安装/设备标识符；
  - 应用程序生命周期事件（游戏启动、正常/异常退出代码、应用版本号）；
  - 身份验证提供方类型（例如微软账号或离线模式验证标识）；
  - 基础运行环境参数（操作系统、Java 运行时版本、CPU 架构）；
  - 崩溃错误日志与堆栈跟踪信息。
- **脱敏与凭据保护：** 在技术可行的范围内，崩溃诊断日志会自动剥离敏感文件路径、用户名及系统令牌。我们**绝不**处理或存储您的微软/Mojang 账号密码、凭据或会话令牌。
