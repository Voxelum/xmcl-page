## 2. 处理的信息与最小必要原则

本项目严格遵循“最小必要”与“数据脱敏”原则：

### 公共网站 (xmcl.app)
- **聚合统计：** 借助 Microsoft Azure Application Insights 记录匿名页面访问量、下载版本选择、基础网络及浏览器类型。
- **技术 Cookie：** 仅使用本地 Cookie 记录您的界面语言偏好，不使用任何第三方营销、广告或跨网站追踪 Cookie。

### 开源启动器
- **单独同意与默认关闭 (Opt-in)：** 诊断遥测数据收集**默认处于关闭状态**。仅在您于启动器设置中主动开启对应开关（单独同意）时，才会传输以下技术数据：
  - 随机生成的匿名化/假名化设备标识符（无法识别特定自然人）；
  - 游戏启动与退出状态、程序退出代码；
  - 启动器版本号、Java 运行时版本、操作系统架构；
  - 崩溃与异常堆栈跟踪（Stack Trace）。
- **严格脱敏与安全保障：** 错误日志会自动过滤与剔除系统用户名、绝对文件路径等敏感信息。我们**绝不**收集或存储您的 Microsoft/Mojang 账户密码、访问令牌或支付凭据。

## 3. 未成年人个人信息保护

- 根据相关法律规定，已满 **14 周岁** 的未成年人可自行同意处理其个人信息。
- 如果您是不满 **14 周岁** 的未成年人（儿童），在使用涉及技术数据收集的功能前，必须事先征得您的父母或其他监护人的明确同意。
- 若我们发现在未获监护人同意的情况下收集了不满 14 周岁未成年人的个人信息，将立即予以删除。

## 4. 存储期限

我们严格杜绝无限期存储：
- 所有诊断日志、错误堆栈和技术遥测数据**最长仅保存 90 天**，期满后将自动永久删除或进行不可逆的匿名化处理。
- 在 GitHub Issues 中公开提交的技术讨论由 GitHub 平台规则与开源项目治理规范管理。

## 5. 个人信息跨境传输与单独同意

- **境外服务提供商：** 为保障全球开源分发与基础设施稳定性，项目使用了位于境外的云基础设施（Microsoft Azure、Cloudflare、GitHub、Vercel）。
- **单独同意要求：** 依据 PIPL 要求，若您开启遥测或向我们提交崩溃工单，即代表您对向境外基础设施提供必要诊断数据给予**单独同意**。我们通过标准合同条款与加密传输保障数据安全。
- **免责与风险告知：** 本项目为国际开源项目，未在中国境内设立实体。用户开启遥测或提交工单，即视为用户知悉并主动同意将其必要的去标识化技术数据传输至境外服务器，且自行承担相关跨境传输风险。
- **不进行商业出售：** 我们承诺绝不向任何第三方出售个人信息，亦不用于个性化商业广告推荐。
