# XMCL 开源项目隐私说明

**生效日期：2026 年 8 月 14 日 · 版本：OP1-2026-08-14**

本说明适用于 XMCL 公共网站和免费开源启动器，不适用于 XMCL Together 的账户、账单、AI、信令、TURN 或其他可选托管服务；这些服务适用 [XMCL Together 隐私政策](./together/privacy)。

## 处理的信息

网站使用 Microsoft Azure Application Insights 记录页面浏览、下载选择、大致网络和设备信息、浏览器信息及诊断事件，并保存语言偏好 Cookie。

启动器可能发送随机生成的安装或设备标识符、游戏启动与退出事件、登录事件、登录服务名称、启动参数、游戏退出代码、应用版本、操作系统信息和包含堆栈的异常错误。诊断字段有时可能包含文件路径、实例名称、用户名、服务器地址或错误及启动配置中的值。

支持请求和公开 issue 包含你主动提交的信息。分享日志前请先检查，不要公开密码、访问令牌、支付资料或无关个人信息。

## 用途与共享

我们使用这些信息提供下载、了解可靠性、诊断故障、保护项目基础设施并改进 XMCL。Microsoft Azure、Vercel、GitHub 以及为支持、可靠性或安全工作确有需要的维护者可能处理这些信息。我们不出售个人信息，也不将启动器遥测用于跨场景行为广告。

## 选择、保留与联系

你可以在启动器提供相应设置时关闭可选遥测、通过浏览器拦截网站 Cookie 或脚本，并在提交 issue 前删除敏感字段。遥测和诊断信息按照适合可靠性及安全用途的滚动周期保留；GitHub 公开内容适用 GitHub 控制和项目管理规则。

如需访问、更正或删除符合条件的非公开项目数据，请通过 **cijhn@hotmail.com** 联系 CI010。XMCL 不面向 13 岁以下儿童。

XMCL 是独立开源项目，与 Microsoft 或 Mojang Studios 没有关联，也未获得其认可。
