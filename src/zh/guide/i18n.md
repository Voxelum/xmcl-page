# 本地化与翻译入门指南

感谢您协助翻译 XMCL！本指南将介绍环境配置、文件结构、各大编辑器（**VS Code**、**Zed Editor**、**Neovim**、**JetBrains**）的设置、本地测试及提交 PR。

---

## 编辑器配置指南

::: code-group
```markdown [VS Code]
安装 **i18n Ally** 插件 (`lokalise.i18n-ally`)。
```

```sh [Zed Editor]
1. 安装 `YAML` 和 `Vue` 拓展。
2. 双栏分屏打开 `en.yaml` 和目标语言 `zh-CN.yaml` (`Cmd+Shift+E` / `Ctrl+Shift+E` -> Split Right)。
```

```vim [Neovim]
:e xmcl-keystone-ui/locales/en.yaml
:vsplit xmcl-keystone-ui/locales/zh-CN.yaml
:set scrollbind
```

```markdown [JetBrains / WebStorm]
安装 **i18n Ally** 插件，使用分屏模式对比编辑。
```
:::
