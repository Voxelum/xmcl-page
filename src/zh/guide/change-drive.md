# 如何将 XMCL 及游戏数据移动到其他磁盘

在安装 X Minecraft Launcher 或下载众多 Minecraft 版本、整合包、Mod 和光影时，系统盘（`C:` 盘）可能会迅速满载。

本指南将介绍如何**移动启动器应用程序**以及**将 Minecraft 游戏数据迁移**至其他磁盘（如 `D:` 或 `E:` 盘）。

:::tip 快捷建议
如果您只是想释放 `C:` 盘空间，您只需要在 XMCL 设置中**[更改游戏数据目录](#1-迁移-minecraft-游戏数据-推荐)**。游戏数据（Mod、存档、版本）占用了 99% 的空间！
:::

---

## 1. 迁移 Minecraft 游戏数据（推荐）

XMCL 允许您将所有大型 Minecraft 文件保存在任意磁盘上，而无需重新安装启动器。

### 更改数据目录步骤：
1. 启动 **X Minecraft Launcher**。
2. 打开**设置**（左下角齿轮图标 ⚙️）。
3. 前往**全局设置** -> **通用 / 存储**。
4. 找到**数据目录 / 路径**设置。
5. 点击**浏览** / **更改路径**，选择目标磁盘上的文件夹（例如 `D:\XMCL-Data`）。
6. 确认选择。XMCL 将自动在新的位置存储所有当前与未来的游戏版本及资源！

---

## 2. 移动启动器可执行程序

根据您安装 XMCL 时的包格式，移动启动器程序的方法有所不同：

### 选项 A：便携 ZIP 包（Portable）
- **方法**：关闭启动器，将解压后的 `XMCL` 文件夹直接复制或剪切到新磁盘（如 `D:\Games\XMCL`），直接运行 `xmcl.exe` 即可。

### 选项 B：AppX / 联机安装包 (AppInstaller) / WinGet
- **通过 Windows 设置移动**：
  1. 按 `Win + I` 打开 **Windows 设置**。
  2. 前往 **应用** -> **安装的应用**（或 *应用和功能*）。
  3. 搜索 **X Minecraft Launcher**。
  4. 点击右侧的三点菜单 `...` 并选择 **移动**。
  5. 选择目标磁盘（例如 `D:` 盘）并点击 **移动**。Windows 会安全地将程序及其沙盒数据迁移到新磁盘。

### 选项 C：macOS (DMG)
- 将 `X Minecraft Launcher.app` 拖动至其他磁盘卷，或保持在 `/Applications` 中并在启动器设置内将数据目录更改为外置磁盘。

### Option D: Linux (AppImage / Flatpak / Deb / RPM)
- 便携 AppImage 文件可直接放置在任意挂载点；Deb/RPM 可在启动器内更改数据目录。
