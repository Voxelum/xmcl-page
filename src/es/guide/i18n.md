# Guía de localización y traducción

¡Gracias por ayudar a traducir X Minecraft Launcher (XMCL)!

---

## Configuración de editores

::: code-group
```markdown [VS Code]
Instala la extensión **i18n Ally** (`lokalise.i18n-ally`).
```

```sh [Zed Editor]
1. Instala las extensiones `YAML` y `Vue`.
2. Abre `en.yaml` y tu idioma objetivo lado a lado (`Ctrl+Shift+E` -> Split Right).
```

```vim [Neovim]
:e xmcl-keystone-ui/locales/en.yaml
:vsplit xmcl-keystone-ui/locales/es.yaml
:set scrollbind
```
:::
