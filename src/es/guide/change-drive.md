# Cómo mover XMCL y los datos del juego a otro disco

Al instalar X Minecraft Launcher o descargar muchas versiones, mods y shaders, el disco del sistema (`C:`) puede llenarse rápidamente.

Esta guía explica cómo **mover la aplicación del launcher** y **relocalizar los datos del juego Minecraft** a otro disco (como `D:` o `E:`).

:::tip Recomendación rápida
Si solo deseas liberar espacio en el disco `C:`, solo necesitas **[cambiar el directorio de datos del juego](#1-relocalizar-los-datos-del-juego-minecraft-recomendado)** en la configuración de XMCL.
:::

---

## 1. Relocalizar los datos del juego Minecraft (Recomendado)

1. Abre **X Minecraft Launcher**.
2. Ve a **Configuración** (icono de engranaje ⚙️).
3. Ve a **Configuración global** -> **General / Almacenamiento**.
4. Cambia la **Ruta del directorio de datos** a tu nuevo disco (ej. `D:\XMCL-Data`).

---

## 2. Mover la aplicación Launcher

- **ZIP Portable**: Simplemente mueve la carpeta `XMCL` descomprimida a tu nuevo disco.
- **AppX / WinGet / AppInstaller**: Abre **Configuración de Windows** (`Win + I`) -> **Aplicaciones** -> **Aplicaciones instaladas** -> **X Minecraft Launcher** -> `...` -> **Mover** al disco `D:`.
