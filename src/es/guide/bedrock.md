# Guía de Minecraft Bedrock Edition

X Minecraft Launcher (XMCL) admite la gestión, descarga y ejecución de **Minecraft Bedrock Edition** (*Windows 10/11 Edition* / *UWP Edition*).

---

## 1. Requisitos del sistema (Solo Windows)

### Activar el Modo Desarrollador de Windows
1. Abre la **Configuración de Windows** (`Win + I`).
2. Ve a **Privacidad y seguridad** -> **Para desarrolladores**.
3. Activa el **Modo Desarrollador**.

---

## 2. Origen de los paquetes

Los paquetes (`.appx`) se descargan directamente desde el **CDN oficial de descargas de Microsoft (Windows Update)**.

---

## 3. Compatibilidad de SO

| Sistema Operativo | Estado | Detalles |
| :--- | :--- | :--- |
| 💻 **Windows 10 / 11** | ✅ **Totalmente compatible** | Entorno UWP nativo. |
| 🍎 **macOS** | ❌ **No compatible** | Requiere API UWP de Windows. Juega a la **Java Edition**. |
| 🐧 **Linux** | ❌ **No compatible** | Requiere API UWP de Windows. Juega a la **Java Edition**. |
