# Comment déplacer XMCL et les données de jeu sur un autre disque

Lors de l'installation d'XMCL ou du téléchargement de nombreuses versions, mods et shaders, le disque système (`C:`) peut rapidement se remplir.

Ce guide explique comment **déplacer l'application launcher** et **réorienter les données de jeu Minecraft** vers un autre disque (comme `D:` ou `E:`).

:::tip Recommandation rapide
Si vous souhaitez simplement libérer de l'espace sur `C:`, il vous suffit de **[modifier le répertoire des données de jeu](#1-deplacer-les-donnees-de-jeu-minecraft-recommande)** dans les paramètres XMCL.
:::

---

## 1. Déplacer les données de jeu Minecraft (Recommandé)

1. Lancez **XMCL**.
2. Ouvrez les **Paramètres** (icône d'engrenage ⚙️ en bas à gauche).
3. Accédez à **Paramètres globaux** -> **Général / Stockage**.
4. Modifiez le **Répertoire des données / Chemin** vers votre nouveau disque (ex: `D:\XMCL-Data`).

---

## 2. Déplacer l'application Launcher

- **ZIP Portable** : Déplacez simplement le dossier `XMCL` décompressé vers votre nouveau disque.
- **AppX / WinGet / AppInstaller** : Ouvrez les **Paramètres Windows** (`Win + I`) -> **Applications** -> **Applications installées** -> **XMCL** -> `...` -> **Déplacer** vers le disque `D:`.
