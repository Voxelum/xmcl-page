# Guide Minecraft Bedrock Edition

X Minecraft Launcher (XMCL) prend en charge la gestion, le téléchargement et le lancement de **Minecraft Bedrock Edition** (*Windows 10/11 Edition* / *UWP Edition*).

---

## 1. Configuration requise (Windows uniquement)

### Activer le Mode Développeur Windows
1. Ouvrez les **Paramètres Windows** (`Win + I`).
2. Allez dans **Confidentialité et sécurité** -> **Espace développeurs**.
3. Activez le **Mode Développeur**.

---

## 2. Origine des paquets

Les paquets (`.appx`) sont téléchargés directement depuis le **CDN officiel de Microsoft (Windows Update Delivery)**.

---

## 3. Compatibilité OS

| Système d'exploitation | Statut | Détails |
| :--- | :--- | :--- |
| 💻 **Windows 10 / 11** | ✅ **Pleinement supporté** | Environnement UWP natif. |
| 🍎 **macOS** | ❌ **Non supporté** | Nécessite des API UWP Windows. Utilisez la **Java Edition**. |
| 🐧 **Linux** | ❌ **Non supporté** | Nécessite des API UWP Windows. Utilisez la **Java Edition**. |
