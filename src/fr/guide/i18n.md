# Guide de localisation et de traduction

Merci de contribuer à la traduction de X Minecraft Launcher (XMCL) !

---

## Configuration des éditeurs

::: code-group
```markdown [VS Code]
Installez l'extension **i18n Ally** (`lokalise.i18n-ally`).
```

```sh [Zed Editor]
1. Installez les extensions `YAML` et `Vue`.
2. Ouvrez `en.yaml` et votre langue cible côte à côte (`Cmd+Shift+E` -> Split Right).
```

```vim [Neovim]
:e xmcl-keystone-ui/locales/en.yaml
:vsplit xmcl-keystone-ui/locales/fr.yaml
:set scrollbind
```
:::
