## 2. Өңделетін ақпарат және деректерді барынша азайту

XMCL деректерді барынша азайту қағидаттарын қатаң сақтайды:

### Жария веб-сайт (xmcl.app)
- **Cookie файлдарынсыз агрегацияланған аналитика:** біз анонимді бет қаралымдарын, жүктеу таңдауларын, жалпы желі/құрылғы параметрлерін және браузердің User-Agent тақырыптарын есепке алу үшін **Microsoft Azure East Asia (Гонконг)** аймағында орналасқан, **cookie-сіз режимде** (`disableCookiesUsage: true`) бапталған Microsoft Azure Application Insights қызметін пайдаланамыз. Құрылғыңызға аналитикалық немесе сайтаралық қадағалау cookie файлдары орнатылмайды.
- **Қатаң қажетті cookie файлы:** біз интерфейс тілін есте сақтау үшін қатаң қажетті тек бір ғана жергілікті функционалдық cookie файлын (`nf_lang`) сақтаймыз. Біз үшінші тараптың маркетингтік, жарнамалық немесе мінез-құлықтық қадағалау cookie файлдарын пайдаланбаймыз.

### Бастапқы коды ашық лаунчер
- **Ерікті телеметрия және диагностика (Opt-in):** диагностикалық телеметрия **әдепкі бойынша өшірулі**. Тек лаунчер баптауларында телеметрияны өз еркіңізбен қосқан жағдайда ғана (Opt-in) лаунчер мыналарды өңдей алады:
  - кездейсоқ жасалған бүркеншік орнату/құрылғы идентификаторын;
  - қосымшаның өмірлік цикл оқиғаларын (ойынды іске қосу, қалыпты аяқталу немесе қате кодтары, қосымша нұсқасы);
  - аутентификация провайдерінің түрін (мысалы, Microsoft немесе офлайн идентификаторы);
  - орындалу ортасының базалық параметрлерін (операциялық жүйе, Java нұсқасы, процессор архитектурасы);
  - істен шығу журналдары мен қате стектерін.
- **Деректерді тазарту және есептік деректер:** істен шығу журналдары мүмкіндігінше сезімтал файл жолдарынан, пайдаланушы аттарынан және жүйелік токендерден тазартылады. Біз сіздің Microsoft/Mojang аккаунттарыңыздың құпиясөздерін, есептік деректерін немесе сессия токендерін **ешқашан** өңдемейміз және сақтамаймыз.
