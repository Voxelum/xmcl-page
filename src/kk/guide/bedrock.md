# Minecraft Bedrock Edition нұсқаулығы

XMCL **Minecraft Bedrock Edition** (*Windows 10/11 Edition* / *UWP Edition*) нұсқасын басқаруды, жүктеуді және іске қосуды қолдайды.

---

## 1. Жүйелік талаптар (Тек Windows)

### Windows Әзірлеуші режимін қосу
1. **Windows Параметрлерін** (`Win + I`) ашыңыз.
2. **Құпиялылық және қауіпсіздік** -> **Әзірлеушілер үшін** бөліміне өтіңіз.
3. **Әзірлеуші режимін** қосыңыз.

---

## 2. Пакеттер қайдан алынады?

Пакеттік файлдар (`.appx`) тікелей **Microsoft ресми Windows Update CDN** серверінен жүктеледі.

---

| Опереционды жүйе | Күйі | Мәліметтер |
| :--- | :--- | :--- |
| 💻 **Windows 10 / 11** | ✅ **Толық қолдау** | Нативті UWP ортасы. |
| 🍎 **macOS** | ❌ **Қолдау көрсетілмейді** | Windows UWP API талап етеді. **Java Edition** ойнаңыз. |
| 🐧 **Linux** | ❌ **Қолдау көрсетілмейді** | Windows UWP API талап етеді. **Java Edition** ойнаңыз. |
