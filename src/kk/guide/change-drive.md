# XMCL мен ойын деректерін басқа дискіге жылжыту жолы

XMCL бағдарламасын орнату немесе көптеген Minecraft нұсқаларын, модтарды жүктеу кезінде жүйелік диск (`C:`) тез толып кетуі мүмкін.

Бұл нұсқаулық **лаунчер қолданбасын жылжыту** және **Minecraft ойын деректерін** басқа дискіге (`D:` немесе `E:`) ауыстыру жолын түсіндіреді.

:::tip Жылдам ұсыныс
Егер сіз тек `C:` дискісіндегі орынды босатқыңыз келсе, XMCL параметрлерінде **[Ойын деректерінің каталогын өзгерту](#1-minecraft-ойын-деректерін-көшіру-ұсынылады)** жеткілікті.
:::

---

## 1. Minecraft ойын деректерін көшіру (Ұсынылады)

1. **XMCL** іске қосыңыз.
2. **Параметрлер** ⚙️ -> **Жалпы параметрлер** -> **Жалпы / Сақтау** бөліміне өтіңіз.
3. **Деректер каталогы / Жол** параметрін жаңа дискідегі қалтаға өзгертіңіз (мысалы, `D:\XMCL-Data`).

---

## 2. Лаунчер қолданбасын жылжыту

- **Портативті ZIP**: Чығарылған `XMCL` қалтасын жаңа дискіге жылжытыңыз.
- **AppX / WinGet**: **Windows Параметрлері** (`Win + I`) -> **Қолданбалар** -> **Орнатылған қолданбалар** -> **XMCL** -> `...` -> **Жылжыту** таңдап, `D:` дискісін белгілеңіз.
