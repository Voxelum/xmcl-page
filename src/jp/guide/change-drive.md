# XMCL とゲームデータを別のドライブに移動する方法

X Minecraft Launcher のインストールや、多数の Minecraft バージョン、Mod、シェーダーをダウンロードすると、システムドライブ（`C:`）の空き容量がすぐに不足する可能性があります。

このガイドでは、**ランチャー本体の移動方法**と**Minecraft ゲームデータの別ドライブ（`D:` や `E:` など）への移行方法**を解説します。

:::tip おすすめ
`C:` ドライブの容量を空けたいだけであれば、XMCL の設定から**[ゲームデータディレクトリを変更](#1-minecraft-ゲームデータの移行-推奨)**するだけで十分です。ゲームデータ（Mod、ワールド、バージョン）が占有容量の99%を占めています！
:::

---

## 1. Minecraft ゲームデータの移行（推奨）

1. **X Minecraft Launcher** を起動します。
2. 左下の⚙️**設定**を開きます。
3. **全般設定** -> **全般 / ストレージ** に移動します。
4. **データディレクトリ / パス** を新しいドライブのフォルダ（例: `D:\XMCL-Data`）に変更します。

---

## 2. ランチャー本体の移動

- **ポータブル ZIP パッケージ**: 解凍した `XMCL` フォルダをそのまま新しいドライブに移動してください。
- **AppX / WinGet / AppInstaller**: **Windows の設定** (`Win + I`) -> **アプリ** -> **インストールされているアプリ** -> **X Minecraft Launcher** -> `...` -> **移動** を選択して `D:` ドライブへ移動します。
