## 2. 収集・処理する情報と利用目的（利用目的の特定）

当プロジェクトは、個人情報の保護に関する法律（APPI）に基づき、利用目的を具体的に特定し、必要最小限の情報のみを取り扱います。

### ウェブサイト（xmcl.app）
- **利用目的:** ウェブサイトの利用状況把握、安定したダウンロード配信の維持のため。
- **処理する情報:** Microsoft Azure Application Insightsを通じた匿名のページビュー、選択されたダウンロードファイル、ブラウザ・OS種別。
- **クッキー（Cookie）:** 言語設定を保持するための技術的クッキーのみを使用し、広告・追跡目的のクッキーは一切使用しません。

### オープンソースランチャー
- **利用目的:** ランチャー起動時やゲームプレイ時の予期せぬクラッシュの診断、エラー原因の究明、バージョン修正版の品質向上、およびインフラのセキュリティ確保のため。
- **事前同意に基づく収集（Opt-in）:** テレメトリおよび診断ログの収集は**初期状態で無効**です。ランチャー設定で明示的に有効化した場合にのみ、以下の情報が送信されます:
  - ランダムに生成された仮名化端末識別子（個人を直接特定するものではありません）；
  - ゲームの起動および終了イベント、終了コード；
  - 実行環境情報（OS種別、Javaバージョン、CPUアーキテクチャ）；
  - クラッシュスタックトレース（ユーザー名やローカルパスなどの機微情報は可能な限り自動マスキングされます）。
- **認証情報の保護:** Microsoft/Mojangアカウントのパスワードや認証トークンを収集・保存することは**一切ありません**。

## 3. 保存期間

曖昧な保存期間を排除し、厳格に管理します:
- 診断ログおよびテレメトリデータは**最大90日間**保持され、期間経過後は不可逆的に完全削除または匿名化されます。
- GitHub Issuesで公開された技術報告は、GitHubプラットフォームの利用規約に従って管理されます。

---

## 4. 外国にある第三者への提供（越境データ移転）

- 当プロジェクトは、安定運用のために国際的なクラウドインフラ（Microsoft Azure、Cloudflare、GitHub、Vercelなど）を利用しています。
- ランチャーのテレメトリ機能を有効化した場合、診断データが日本国外（米国や欧州等）のサーバーへ送信されることについて**明示的な同意**をいただいたものとします。
- 当プロジェクトは、個人情報を第三者に販売したり、行動ターゲティング広告の目的で共有したりしません。

---

## 5. 未成年者の個人情報保護

- 日本国内のユーザーにおいて、15歳未満の未成年者がテレメトリの送信や問い合わせを行う場合は、**保護者（法定代理人）の同意**が必要です。
