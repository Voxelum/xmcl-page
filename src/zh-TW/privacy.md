## 2. 蒐集與處理之資訊及最小化原則

XMCL 嚴格遵循資料最小化原則：

### 公開網站（xmcl.app）
- **無 Cookie 聚合分析：** 本站使用設定為**無 Cookie 模式**（`disableCookiesUsage: true`）且資料接收端位於 **Microsoft Azure 東亞（香港）** 之 Microsoft Azure Application Insights，用以記錄匿名頁面瀏覽次數、下載選項、一般網路／裝置屬性及瀏覽器 User-Agent。本站不會在您的裝置上放置任何分析或跨站追蹤 Cookie。
- **絕對必要 Cookie：** 本站僅儲存一個絕對必要之本地功能性 Cookie（`nf_lang`），以記住您的介面語言偏好。本站不使用任何第三方行銷、廣告或行為追蹤 Cookie。

### 開源啟動器
- **選擇加入（Opt-in）之遙測與診斷：** 診斷遙測功能**預設關閉**。僅於您在啟動器設定中明確開啟遙測（選擇加入）時，啟動器方會處理以下資訊：
  - 隨機產生之假名化安裝／裝置識別碼；
  - 應用程式生命週期事件（遊戲啟動、正常／錯誤結束代碼、應用程式版本）；
  - 驗證提供者類型（例如 Microsoft 或離線驗證識別）；
  - 基本執行環境規格（作業系統、Java 執行環境版本、CPU 架構）；
  - 崩潰錯誤日誌與堆疊追蹤（Stack Trace）。
- **去識別化與憑證保護：** 於技術可行範圍內，崩潰診斷資料會自動移除敏感檔案路徑、使用者名稱與系統權杖。我們**絕不**處理或儲存您的 Microsoft／Mojang 帳號密碼、憑證或工作階段權杖。
