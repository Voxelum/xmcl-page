# XMCL 開源專案隱私說明

**生效日期：2026 年 8 月 14 日 · 版本：OP1-2026-08-14**

本說明適用於 XMCL 公共網站和免費開源啟動器，不適用於 XMCL Together 的帳戶、帳務、AI、信令、TURN 或其他選用託管服務；這些服務適用 [XMCL Together 隱私權政策](./together/privacy)。

## 處理的資訊

網站使用 Microsoft Azure Application Insights 記錄頁面瀏覽、下載選擇、大致網路和裝置資訊、瀏覽器資訊及診斷事件，並儲存語言偏好 Cookie。

啟動器可能傳送隨機產生的安裝或裝置識別碼、遊戲啟動與結束事件、登入事件、登入服務名稱、啟動參數、遊戲結束代碼、應用程式版本、作業系統資訊，以及包含堆疊追蹤的非預期錯誤。診斷欄位有時可能包含檔案路徑、實例名稱、使用者名稱、伺服器位址或錯誤及啟動設定中的值。

支援請求和公開 issue 包含你主動提交的資訊。分享日誌前請先檢查，不要公開密碼、存取權杖、付款資料或無關個人資訊。

## 用途與共享

我們使用這些資訊提供下載、瞭解可靠性、診斷故障、保護專案基礎設施並改進 XMCL。Microsoft Azure、Vercel、GitHub，以及為支援、可靠性或安全工作確有需要的維護者可能處理這些資訊。我們不出售個人資訊，也不將啟動器遙測用於跨情境行為廣告。

## 選擇、保留與聯絡

你可以在啟動器提供相應設定時關閉選用遙測、透過瀏覽器封鎖網站 Cookie 或指令碼，並在提交 issue 前移除敏感欄位。遙測和診斷資訊依適合可靠性及安全用途的滾動週期保留；GitHub 公開內容適用 GitHub 控制和專案管理規則。

如需存取、更正或刪除符合條件的非公開專案資料，請透過 **cijhn@hotmail.com** 聯絡 CI010。XMCL 不以 13 歲以下兒童為對象。

XMCL 是獨立開源專案，與 Microsoft 或 Mojang Studios 沒有關聯，也未獲得其認可。
