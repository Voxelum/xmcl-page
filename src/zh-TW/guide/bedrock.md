# Minecraft 基岩版（Bedrock Edition）指南

XMCL 支援管理、下載與啟動 **Minecraft 基岩版**（即 *Windows 10/11 版* 或 *UWP 版*）。

---

## 1. 系統要求與設定（僅限 Windows）

### 開啟 Windows 開發者模式
1. 開啟 **Windows 設定** (`Win + I`)。
2. 前往 **隱私權與安全性** -> **開發者專用**。
3. 開啟 **開發者模式**。

---

## 2. 包檔案來源

包檔案 (`.appx`) 直接從 **Microsoft 官方 Windows Update Delivery CDN** 下載。

---

## 3. 作業系統相容性

| 作業系統 | 相容狀態 | 詳情 |
| :--- | :--- | :--- |
| 💻 **Windows 10 / 11** | ✅ **完全支援** | 原生 UWP 運行環境。 |
| 🍎 **macOS** | ❌ **不支援** | 需要 Windows 獨占 UWP API。請遊玩 **Java 版**。 |
| 🐧 **Linux** | ❌ **不支援** | 需要 Windows 獨占 UWP API。請遊玩 **Java 版**。 |
