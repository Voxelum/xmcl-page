# 如何將 XMCL 及遊戲資料移動到其他磁碟

在安裝 XMCL 或下載眾多 Minecraft 版本、整合包、Mod 與光影時，系統磁碟（`C:` 碟）可能會迅速滿載。

本指南將介紹如何**移動啟動器應用程式**以及**將 Minecraft 遊戲資料遷移**至其他磁碟（如 `D:` 或 `E:` 碟）。

:::tip 快捷建議
如果您只是想釋放 `C:` 碟空間，您只需要在 XMCL 設定中**[更改遊戲資料目錄](#1-遷移-minecraft-遊戲資料-推薦)**。遊戲資料占用了 99% 的空間！
:::

---

## 1. 遷移 Minecraft 遊戲資料（推薦）

1. 啟動 **XMCL**。
2. 開啟**設定**（左下角齒輪圖示 ⚙️）。
3. 前往**全域設定** -> **一般 / 儲存**。
4. 將**資料目錄 / 路徑**更改為目标磁碟（例如 `D:\XMCL-Data`）。

---

## 2. 移動啟動器可執行程式

- **便攜 ZIP 包**：直接剪貼 `XMCL` 資料夾至新磁碟。
- **AppX / WinGet / AppInstaller**：開啟 **Windows 設定** (`Win + I`) -> **應用程式** -> **安裝的應用程式** -> **XMCL** -> `...` -> **移動** 至 `D:` 碟。
