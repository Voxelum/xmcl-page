## 編輯器設定指南

::: code-group
```markdown [VS Code]
安裝 **i18n Ally** 擴充功能 (`lokalise.i18n-ally`)。
```

```sh [Zed Editor]
1. 安裝 `YAML` 與 `Vue` 擴充功能。
2. 雙欄分頁開啟 `en.yaml` 與目標語言 `zh-TW.yaml`。
```

```vim [Neovim]
:e xmcl-keystone-ui/locales/en.yaml
:vsplit xmcl-keystone-ui/locales/zh-TW.yaml
:set scrollbind
```
:::
