## 2. 처리하는 개인정보 항목 및 최소화 원칙

XMCL은 엄격한 데이터 최소화 원칙을 준수합니다.

### 공개 웹사이트(xmcl.app)
- **쿠키 없는 집계 분석:** 당사는 **쿠키리스 모드**(`disableCookiesUsage: true`)로 구성되고 **Microsoft Azure 동아시아(홍콩)** 리전에서 수집되는 Microsoft Azure Application Insights를 사용하여 익명 페이지 조회수, 다운로드 선택, 일반 네트워크/기기 속성 및 브라우저 User-Agent를 기록합니다. 분석용 쿠키나 크로스사이트 추적 쿠키는 이용자 기기에 저장되지 않습니다.
- **필수 기능성 쿠키:** 당사는 인터페이스 언어 설정을 기억하기 위해 반드시 필요한 단일 로컬 기능성 쿠키(`nf_lang`)만을 저장합니다. 제3자 마케팅, 광고 또는 행태 추적 쿠키는 전혀 사용하지 않습니다.

### 오픈소스 런처
- **선택적 동의(Opt-in) 기반 원격 측정 및 진단:** 진단 원격 측정 기능은 **기본적으로 비활성화**되어 있습니다. 이용자가 런처 설정에서 명시적으로 원격 측정을 활성화(Opt-in)한 경우에만 다음 정보를 처리할 수 있습니다.
  - 무작위로 생성된 가명화 설치/기기 식별자
  - 애플리케이션 수명 주기 이벤트(게임 실행, 정상/오류 종료 코드, 앱 버전)
  - 인증 제공자 유형(예: Microsoft 또는 오프라인 인증 식별자)
  - 기본 실행 환경 사양(운영체제, Java 런타임 버전, CPU 아키텍처)
  - 충돌 오류 로그 및 스택 트레이스
- **비식별화 및 자격 증명 보호:** 충돌 진단 데이터에서는 기술적으로 가능한 범위 내에서 민감한 파일 경로, 사용자 이름 및 시스템 토큰을 제거합니다. 당사는 이용자의 Microsoft/Mojang 계정 비밀번호, 자격 증명 또는 세션 토큰을 **결코** 처리하거나 저장하지 않습니다.
