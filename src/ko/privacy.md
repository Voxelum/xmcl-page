## 2. 수집하는 항목 및 수집 목적

프로젝트는 '최소 수집의 원칙'을 엄격히 준수합니다:

### 웹사이트 (xmcl.app)
- **통계 분석:** Microsoft Azure Application Insights를 통해 익명화된 페이지 뷰, 다운로드 버전 선택, 브라우저 및 운영체제 유형을 수집합니다.
- **쿠키(Cookie):** 언어 설정을 유지하기 위한 기술적 쿠키만을 사용하며, 제3자 마케팅 및 추적 쿠키는 사용하지 않습니다.

### 오픈소스 런처
- **선택적 동의 기반 텔레메트리 (Opt-in):** 진단 데이터 수집은 **기본적으로 비활성화**되어 있습니다. 사용자가 런처 설정에서 직접 활성화한 경우에만 수집됩니다:
  - 무작위 생성된 가명화 기기 식별자(개인을 직접 식별할 수 없음);
  - 게임 실행 및 종료 이벤트, 프로세스 종료 코드;
  - 런처 버전, Java 런타임 버전, 운영체제 사양;
  - 오류 및 크래시 스택 트레이스(개인 사용자 이름이나 경로 등은 자동 마스킹 처리).
- **계정 정보 보호:** 사용자의 Microsoft 또는 Mojang 계정 비밀번호나 액세스 토큰은 **절대로 수집하거나 저장하지 않습니다**.

불명확한 보존 일정을 배제하고 명확한 기준을 적용합니다:
- 진단 로그 및 텔레메트리 데이터는 **최대 90일간 보관**되며, 기간 경과 후 복구 불가능한 방법으로 영구 파기되거나 비가역적으로 익명화됩니다.
- GitHub Issues에 공개 등록된 이슈는 GitHub 플랫폼 정책에 따라 보관됩니다.

## 4. 개인정보의 국외 이전

- 본 프로젝트는 글로벌 서비스 인프라(Microsoft Azure, Cloudflare, GitHub, Vercel)를 이용합니다.
- 텔레메트리 수집에 동의하는 경우, 기술적 진단 정보가 해외 서버로 전송되는 것에 대해 명시적으로 동의한 것으로 처리됩니다.
- 당사는 개인정보를 외부에 판매하거나 광고 목적으로 공유하지 않습니다.
