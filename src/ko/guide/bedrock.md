# Minecraft Bedrock Edition 가이드

XMCL는 **Minecraft Bedrock Edition**(*Windows 10/11 Edition* / *UWP Edition*)의 관리, 다운로드 및 실행을 지원합니다.

---

## 1. 시스템 요구 사항 (Windows 전용)

### Windows 개발자 모드 활성화
1. **Windows 설정**(`Win + I`)을 엽니다.
2. **개인 정보 및 보안** -> **개발자용**으로 이동합니다.
3. **개발자 모드**를 **켜기**로 전환합니다.

---

## 2. 패키지 파일 다운로드 출처

패키지 파일(`.appx`)은 **Microsoft 공식 Windows Update Delivery CDN**에서 직접 다운로드됩니다.

---

## 3. OS 호환성

| 운영 체제 | 호환성 상태 | 상세 내용 |
| :--- | :--- | :--- |
| 💻 **Windows 10 / 11** | ✅ **완벽 지원** | 네이티브 UWP 실행 환경. |
| 🍎 **macOS** | ❌ **미지원** | Windows 전용 UWP API가 필요합니다. **Java Edition**을 플레이하세요. |
| 🐧 **Linux** | ❌ **미지원** | Windows 전용 UWP API가 필요합니다. **Java Edition**을 플레이하세요. |
