# XMCL 및 게임 데이터를 다른 드라이브로 이동하는 방법

X Minecraft Launcher를 설치하거나 많은 Minecraft 버전, 모드, 리소스 팩 및 셰이더를 다운로드하면 시스템 드라이브(`C:`) 공간이 빠르게 부족해질 수 있습니다.

이 가이드에서는 **런처 애플리케이션 이동** 및 **Minecraft 게임 데이터를 다른 드라이브(`D:` 또는 `E:`)로 이전**하는 방법을 설명합니다.

:::tip 빠른 추천
`C:` 드라이브 용량만 확보하고 싶다면 XMCL 설정에서 **[게임 데이터 디렉터리 변경](#1-minecraft-게임-데이터-이전-권장)**만 수행하면 됩니다. 게임 데이터(모드, 월드, 버전)가 전체 사용 공간의 99%를 차지합니다!
:::

---

## 1. Minecraft 게임 데이터 이전 (권장)

1. **X Minecraft Launcher**를 실행합니다.
2. 왼쪽 하단의 ⚙️ **설정**을 엽니다.
3. **전체 설정** -> **일반 / 저장소**로 이동합니다.
4. **데이터 디렉터리 / 경로**를 새 드라이브의 폴더(예: `D:\XMCL-Data`)로 변경합니다.

---

## 2. 런처 애플리케이션 파일 이동

- **포터블 ZIP 패키지**: 압축 해제된 `XMCL` 폴더를 새 드라이브로 이동하고 실행합니다.
- **AppX / WinGet / AppInstaller**: **Windows 설정**(`Win + I`) -> **앱** -> **설치된 앱** -> **X Minecraft Launcher** -> `...` -> **이동**을 선택하여 `D:` 드라이브로 이동합니다.
