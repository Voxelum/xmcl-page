# Guida a Minecraft Bedrock Edition

X Minecraft Launcher (XMCL) supporta la gestione, il download e l'avvio di **Minecraft Bedrock Edition** (*Windows 10/11 Edition* / *UWP Edition*).

---

## 1. Requisiti di sistema (Solo Windows)

### Abilita la Modalità Sviluppatore di Windows
1. Apri **Impostazioni di Windows** (`Win + I`).
2. Vai su **Privacy e sicurezza** -> **Per sviluppatori**.
3. Attiva la **Modalità Sviluppatore**.

---

## 2. Da dove provengono i pacchetti?

I pacchetti (`.appx`) vengono scaricati direttamente dal **CDN ufficiale di Windows Update di Microsoft**.

---

## 3. Compatibilità del sistema operativo

| Sistema Operativo | Stato | Dettagli |
| :--- | :--- | :--- |
| 💻 **Windows 10 / 11** | ✅ **Completamente supportato** | Ambiente UWP nativo. |
| 🍎 **macOS** | ❌ **Non supportato** | Richiede le API UWP di Windows. Gioca a **Java Edition**. |
| 🐧 **Linux** | ❌ **Non supportato** | Richiede le API UWP di Windows. Gioca a **Java Edition**. |
