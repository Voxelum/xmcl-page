# Come spostare XMCL e i dati di gioco su un altro disco

Durante l'installazione di X Minecraft Launcher o il download di versioni e mod di Minecraft, il disco di sistema (`C:`) può riempirsi rapidamente.

Questa guida spiega come **spostare l'applicazione launcher** e **riposizionare i dati di gioco Minecraft** su un altro disco (come `D:` o `E:`).

:::tip Raccomandazione rapida
Se vuoi solo liberare spazio su `C:`, devi solo **[modificare la directory dei dati di gioco](#1-spostare-i-dati-di-gioco-minecraft-consigliato)** nelle impostazioni di XMCL.
:::

---

## 1. Spostare i dati di gioco Minecraft (Consigliato)

1. Apri **X Minecraft Launcher**.
2. Vai su **Impostazioni** ⚙️ -> **Impostazioni globali** -> **Generale / Archiviazione**.
3. Modifica la **Percorso directory dati** selezionando una cartella sul nuovo disco (es. `D:\XMCL-Data`).

---

## 2. Spostare l'applicazione Launcher

- **Pacchetto ZIP Portatile**: Sposta semplicemente la cartella `XMCL` estratta sul nuovo disco.
- **AppX / WinGet / AppInstaller**: Apri **Impostazioni di Windows** (`Win + I`) -> **App** -> **App installate** -> **X Minecraft Launcher** -> `...` -> **Sposta** sul disco `D:`.
