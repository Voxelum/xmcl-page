# Управління даними та сховищем

Структура даних X Minecraft Launcher (XMCL) розділена на дві чіткі частини:

1. **Системні конфігурації та база даних XMCL** (налаштування, облікові записи, кеш).
2. **Ігрові дані Minecraft** (версії, збірки, моди, світи, ресурси).

:::tip Переміщення даних на інший диск
Якщо у вас закінчується місце на системному диску `C:`, ви можете легко перенести весь каталог ігрових даних на диск `D:` або `E:`. Детальніше дивіться у [Гайді з переміщення на інший диск](./change-drive.md).
:::

---

## 1. Системний кеш та база даних XMCL

:::tip 💡 Найпростіший спосіб відкрити папку даних
Вам не потрібно шукати приховані папки вручну! У лаунчері перейдіть до **Налаштування ⚙️** -> **Глобальні налаштування** -> **Сховище** та натисніть кнопку **"Відкрити каталог даних"** (Open Data Directory). Лаунчер сам відкриє потрібну папку в Провіднику Windows!
:::

### Точні шляхи системної папки в залежності від типу встановлення:

Якщо ви шукаєте папку вручну через Провідник Windows (натисніть `Win + R` та вставте відповідний шлях):

#### 🔹 Варіант 1: Встановлення через AppX / AppInstaller / WinGet (Основний спосіб)
Оскільки версії AppX працюють у захищеній пісочниці Windows 10/11, вони зберігають дані **НЕ в звичайній папці `Roaming`**, а в системній пісочниці пакетів:
```cmd
%LocalAppData%\Packages\XMCL_68mcaawk44tpj\LocalCache\Roaming\xmcl
```
*(Повний шлях: `C:\Users\<Ваше_Ім'я>\AppData\Local\Packages\XMCL_68mcaawk44tpj\LocalCache\Roaming\xmcl`)*

#### 🔹 Варіант 2: Стандартне встановлення (EXE)
```cmd
%AppData%\xmcl
```
*(Повний шлях: `C:\Users\<Ваше_Ім'я>\AppData\Roaming\xmcl`)*

#### 🔹 Варіант 3: Портативна версія (Portable ZIP)
У портативній версії дані зберігаються безпосередньо у тій самій папці, куди ви розпакували `XMCL` (поруч із файлом `xmcl.exe`), або у вибраному вами каталозі даних.

#### 🔹 macOS & Linux:
- **macOS**: `~/Library/Application Support/xmcl`
- **Linux**: `~/.config/xmcl`

---

### Основні конфігураційні файли:
- **`user.json`** — Облікові записи (Microsoft, Yggdrasil, Offline), токени та посилання на скіни.
- **`settings.json`** — Глобальні налаштування лаунчера (шлях до даних, мова, тема, проксі, дзеркала).
- **`instances.json`** — Список усіх зареєстрованих екземплярів (збірок) та останній вибраний екземпляр.
- **`java.json`** — Кеш виявлених у системі версій Java (Path, Version, Architecture).
- **`resources-v2/`** — База даних LevelDB для індексації метаданих модів, ресурспаків та шейдерів.
- **`logs/`** — Журнали роботи лаунчера (`main.log`, `renderer.log`).

## 2. Каталог ігрових даних Minecraft

Усі важкі файли гри (моди, версії, світи) зберігаються у **Каталозі ігрових даних** (Game Data Directory).

### Структура каталогу ігрових даних:

```sh
📂 Каталог даних XMCL (Game Data Directory)
 ├─ 📂 instances/        # Індивідуальні екземпляри (збірки) Minecraft
 │   ├─ 📂 Fabric-1.20/  # Папка конкретного екземпляра
 │   │   ├─ 📂 saves/        # Світи та збереження для цієї збірки
 │   │   ├─ 📂 options.txt   # Налаштування гри для цієї збірки
 │   │   ├─ 📂 screenshots/  # Скріншоти
 │   │   └─ 📂 mods/         # Жорсткі посилання (Hardlinks) на моди
 ├─ 📂 mods/             # Загальне сховище (пул) усіх завантажених модів
 ├─ 📂 resourcepacks/    # Загальне сховище ресурспаків
 ├─ 📂 shaderpacks/      # Загальне сховище шейдерів
 ├─ 📂 versions/         # Завантажені версії Minecraft (JAR, JSON)
 ├─ 📂 assets/           # Текстури, звуки та ресурси Minecraft
 ├─ 📂 libraries/        # Загальні Java-бібліотеки
 └─ 📂 modpacks/         # Збережені та експортовані модпаки
```

## 3. Як XMCL економить дисковий простір (Hardlinks)

1. Один і той самий мод завантажується лише **один раз** у загальну папку `mods/`.
2. При додаванні мода до декількох збірок XMCL створює **жорстке посилання (Hardlink)** в папку відповідного екземпляра.
3. **Результат**: 10 збірок з однаковими модами займають на диску стільки ж місця, скільки 1 збірка!
