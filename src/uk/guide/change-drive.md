# Як перемістити XMCL та дані гри на інший диск

При встановленні XMCL або завантаженні багатьох версій Minecraft, модів, ресурспаків та шейдерів системний диск (`C:`) може швидко заповнитися.

Цей гайд пояснює, як **перемістити сам лаунчер** та **перенести ігрові дані Minecraft** на інший диск (наприклад, `D:` або `E:`).

:::tip Швидка рекомендація
Якщо ваша головна мета — звільнити місце на диску `C:`, достатньо лише **[змінити каталог даних гри](#1-перенесення-ігрових-даних-minecraft-рекомендовано)** у налаштуваннях XMCL. Ігрові дані (моди, світи, версії) займають 99% усього обсягу!
:::

---

## 1. Перенесення ігрових даних Minecraft (Рекомендовано)

XMCL дозволяє зберігати всі важкі файли Minecraft (версії, моди, екземпляри, ресурспаки, асети) на будь-якому диску без перевстановлення лаунчера.

### Кроки для зміни каталогу даних:
1. Запустіть **XMCL**.
2. Відкрийте **Налаштування** (іконка шестерні ⚙️ у лівому нижньому кутку).
3. Перейдіть до **Глобальні налаштування** -> **Загальні / Сховище**.
4. Знайдіть пункт **Каталог даних / Шлях**.
5. Натисніть **Огляд** / **Змінити шлях** та виберіть папку на потрібному диску (наприклад, `D:\XMCL-Data` або `E:\MinecraftData`).
6. Підтвердіть вибір. XMCL автоматично використовуватиме нове місце для всіх поточних та майбутніх збірок Minecraft, модів і завантажень!

---

## 2. Переміщення виконуваного файлу лаунчера

Залежно від формату пакета, використаного для встановлення XMCL, переміщення програми виконується різними способами:

### Варіант A: Портативний пакет ZIP (Portable)
- **Особливості**: Повністю автономний та портативний.
- **Як перемістити**:
  1. Закрийте XMCL, якщо він запущений.
  2. Просто скопіюйте або виріжте розпаковану папку `XMCL` з диска `C:\` на новий диск (наприклад, `D:\Games\XMCL`).
  3. Запускайте `xmcl.exe` безпосередньо з нової директорії. Ви можете створити ярлик на робочому столі для `xmcl.exe`.

### Варіант B: AppX / Online AppInstaller / WinGet
- **Чому звичайне копіювання не працює**: AppX, AppInstaller та WinGet встановлюють XMCL як захищений пакет Windows у системні каталоги (`C:\Program Files\WindowsApps` та `%LocalAppData%\Packages`). Ручне копіювання цих папок у Провіднику призведе до помилок доступу Windows.
- **Як перемістити через Налаштування Windows**:
  1. Натисніть `Win + I`, щоб відкрити **Налаштування Windows**.
  2. Перейдіть до **Програми** -> **Установлені програми** (або *Програми та можливості*).
  3. Знайдіть у списку **XMCL**.
  4. Натисніть на три крапки `...` поруч із XMCL та виберіть **Перемістити**.
  5. Виберіть цільовий диск (наприклад, `D:`) зі списку та натисніть **Перемістити**. Windows безпечно перенесе програму та її дані на вибраний диск.

:::tip Зміна диска встановлення AppX за замовчуванням
Щоб майбутні програми AppX / WinGet встановлювалися на інший диск за замовчуванням:
Відкрийте **Налаштування** -> **Система** -> **Сховище** -> **Додаткові параметри сховища** -> **Де зберігається новий вміст** -> Змініть *Нові програми зберігатимуться в:* на диск `D:`.
:::

### Варіант C: macOS (DMG)
- Перетягніть `XMCL.app` з папки `/Applications` на будь-який підключений диск або залишіть програму в `/Applications`, змінивши каталог даних гри в налаштуваннях лаунчера на зовнішній диск.

### Варіант D: Linux (AppImage / Flatpak / Deb / RPM)
- Для **AppImage**: просто перемістіть файл `.AppImage` на будь-який змонтований розділ (наприклад, `/media/data/XMCL.AppImage`).
- Для **Deb / RPM / Flatpak**: системні бінарні файли залишаються в системних шляхах, але всі важкі файли гри можна спрямувати на інший диск через **Розділ 1**.
