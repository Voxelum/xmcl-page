# Посібник зі встановлення

XMCL надає кілька форматів встановлення, оптимізованих для Windows, macOS та Linux.

:::tip Корисні посібники
- **Потрібно перенести лаунчер чи саму гру на диск D: або E:?** Читайте [Посібник зі зміни диска](./change-drive.md).
- **Хочете грати у Minecraft Bedrock Edition (Windows 10/11)?** Читайте [Посібник з Bedrock Edition](./bedrock.md).
:::

## Windows

Для користувачів Windows доступно кілька варіантів встановлення:

### 1. APPX та Онлайн-встановлення (appinstaller) — Рекомендовано
- **APPX** — це сучасний формат пакетів Windows 10/11. Програма працює в безпечному віртуалізованому середовищі. При видаленні лаунчера всі тимчасові файли та записи реєстру видаляються автоматично.
- **AppInstaller** — автоматично завантажує та оновлює AppX пакет через захищені канали Microsoft. Підтримує **інкрементні оновлення** (завантажуються лише змінені файли).

### 2. Портативний архів (Portable ZIP)
- Не вимагає встановлення чи прав адміністратора.
- Ви можете розпакувати файл у будь-яку папку (наприклад, `D:\Games\XMCL`) та відразу запускати `xmcl.exe`.
- Ідеально підходить для запуску з флешки або другого диска.

### 3. DeskGap (Windows x64) — Ультралегкий пакунок (v0.72.0+)
- **Що таке DeskGap?** Починаючи з версії XMCL **0.72.0**, став доступний офіційний полегшений збірочний пакет, побудований на базі DeskGap та системного рушія **Microsoft Edge WebView2**.
- **Чим він особливий?**
  - **Вражаюче малий розмір завантаження**: Стандартний Electron змушений постачати повноцінний рушій Chromium (~120–160 МБ). DeskGap використовує вже встановлений у системі Windows компонент WebView2, завдяки чому розмір архіву лаунчера становить лише **~15–25 МБ** (економія понад 80% трафіку та диска).
  - **Зменшене споживання оперативної пам'яті (RAM)**: Повторно використовує системні процеси веб-рендерингу замість запуску додаткових важких процесів, звільняючи оперативну пам'ять для великих модпаків Minecraft.
  - **Швидкий холодний старт**: Лаунчер запускається майже миттєво, оскільки базовий веб-рушій уже кешується системою.
  - **Повний функціонал**: Зберігає 100% можливостей лаунчера, включаючи Node.js бекенд, P2P WebRTC мультиплеєр, завантажувачі модів та вбудований AI Agent.
- **Вимога**: Windows 10 (з встановленим компонентом WebView2) або Windows 11 (входить до складу системи за замовчуванням).

### 4. Запуск на Windows 7 / 8 / 8.1 (VxKex Kernel)

:::warning Важливе зауваження про сумісність
Сучасний XMCL побудований на базі **Electron 43 / Chromium 130+**. Офіційно Chromium та Microsoft **повністю припинили підтримку Windows 7, 8 та 8.1**. Нативно лаунчер на застарілих системах Windows **не запуститься**.
:::

:::details Технічна можливість запуску через ядро VxKex
Ви можете запустити XMCL на Windows 7 / 8 за допомогою неофіційного розширеного ядра **VxKex**:

1. Завантажте та встановіть розширене ядро [VxKex-NEXT](https://github.com/YuZhouRen86/VxKex-NEXT).
2. Клацніть правою кнопкою миші на `xmcl.exe` -> **Властивості** -> вкладка **VxKex**.
3. Позначте пункти **"Enable VxKex NEXT for this program"** та **"Report other versions of Windows"**, після чого натисніть **Застосувати**.

**Стан сумісності на Windows 7/8:**
- **Одиночна гра (Java Edition)** — працює нормально при встановленні відповідної версії Java (Java 8 / 17 / 21).
- **P2P Мережева гра (WebRTC)** — не працює (потрібен мережевий стек Windows 10+).
- **Bedrock Edition (UWP)** — не працює (вимагає системний UWP фреймворк Windows 10/11).
:::

## macOS

### DMG Пакет
1. Завантажте та відкрийте файл `.dmg`.
2. Перетягніть **XMCL.app** у папку **Програми (Applications)**.

:::warning Попередження Gatekeeper
Якщо macOS блокує запуск програми через відсутність підпису Apple, виконайте таку команду в Terminal:

```sh
sudo xattr -c /Applications/XMCL.app
```
:::

## Linux

Для систем Linux XMCL зосереджений на підтримці сучасних універсальних пакетів (пакет Snap відсутній, а підтримка AUR для Arch Linux припинена на користь офіційного Flatpak):

### 1. Flatpak (Flathub) — Рекомендовано
- Офіційний рекомендований спосіб встановлення для **Arch Linux**, **Fedora**, **Ubuntu**, **Debian** та **Steam Deck (SteamOS)**.
- Забезпечує стабільну роботу, автоматичну ізоляцію та зручні оновлення через Flathub:
  ```sh
  flatpak install flathub app.xmcl.XMCL
  ```

### 2. AppImage — Універсальний портативний файл
- Автономний бінарний файл, що працює без встановлення на будь-якому дистрибутиві:
  ```sh
  chmod +x xmcl-*.AppImage
  ./xmcl-*.AppImage
  ```
- Ідеально підходить для **Steam Deck (режим SteamOS Desktop)**.

### 3. Автономний Tarball (.tar.xz) та пакети дистрибутивів
- Доступні чисті архіви `.tar.xz`, а також пакети `.deb` (Debian/Ubuntu) та `.rpm` (Fedora/RHEL/openSUSE) на сторінці релізів.
