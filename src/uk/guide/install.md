# Посібник з вибору пакета та інсталяції XMCL

Лаунчер XMCL надає багато варіантів завантаження та інсталяції для різних операційних систем. Цей посібник допоможе вам розібратися у відмінностях між пакетами, дізнатися, як вони працюють, та вибрати **найкращий варіант** для вашого пристрою.

---

## 💻 Варіанти для Windows

### 1. App Інсталятор (`.appinstaller`) ⭐ *Рекомендовано для Windows 10/11*
* **Принцип роботи:** Онлайн-інсталятор від Microsoft. При запуску автоматично завантажує та встановлює найновішу версію XMCL з офіційних серверів Microsoft CDN.
* **Головні переваги:**
  * **Автоматичні фонові оновлення:** Лаунчер самостійно оновлюється при кожному запуску.
  * **Інкрементні (дельта) оновлення:** Завантажуються лише змінені файли, що економить інтернет-трафік і час.
* **Кому підходить:** Більшості користувачів Windows 10 та 11, яким потрібні автоматичні оновлення без ручного перезавантаження.

---

### 2. AppX Пакет (`.appx` / `.msix`)
* **Принцип роботи:** Нативний файл пакету Windows UWP/MSIX. Встановлюється в захищеному контейнері Windows App Container.
* **Головні переваги:**
  * **Ізоляція системи:** Усі тимчасові файли та записи реєстру ізольовані всередині контейнера.
  * **Чисте видалення:** При видаленні програми з системи повністю видаляються всі кэш-файли без залишку сміття.
* **Кому підходить:** Користувачам Windows 10/11, які надають перевагу прямим інсталяційним файлам із захистом пісочниці.

---

### 3. Zip (x64) Портативний архів
* **Принцип роботи:** Звичайний `.zip` архів, який містить портативну (Portable) версію лаунчера.
* **Головні переваги:**
  * **Не потребує інсталяції:** Розпакуйте в будь-яку папку та запускайте `X Minecraft Launcher.exe`.
  * **Без прав адміністратора:** Працює на гостьових акаунтах та ПК з обмеженими правами (школа/робота).
  * **Портативність:** Можна записати на USB-флешку та носити з собою.
* **Кому підходить:** Досвідченим користувачам, для запусків з флешки або ПК без прав адміністратора.

---

### 4. WinGet CLI
* **Принцип роботи:** Інсталяція через офіційний менеджер пакетів Windows у консолі.
* **Команда:** `winget install CI010.XMinecraftLauncher`
* **Кому підходить:** Користувачам, які полюбляють командний рядок та автоматизацію.

---

### 💻 Підтримка старіших систем (Windows 7 / 8)

:::details Запуск XMCL на Windows 7 / 8 (через VxKex)
За замовчуванням XMCL вимагає Windows 10+. Користувачі Windows 7 можуть запустити лаунчер за допомогою розширеного ядра **VxKex**:
1. Завантажте та встановіть [VxKex-NEXT](https://github.com/YuZhouRen86/VxKex-NEXT).
2. Натисніть правою кнопкою миші на `X Minecraft Launcher.exe` -> **Властивості** -> вкладка **VxKex**.
3. Увімкніть "Enable VxKex NEXT for this program" та "Report other versions of Windows", після чого застосуйте налаштування.
4. XMCL працюватиме на Windows 7 (працюють усі функції, окрім P2P мультиплеєра).
:::

## 🍎 Варіанти для macOS

### 1. DMG Дисковий образ (`x64` / `ARM64`) ⭐ *Рекомендовано для Mac*
* **Варіанти архітектури:**
  * **ARM64:** Оптимізована нативна версія для процесів Apple Silicon (чіпи **M1, M2, M3, M4**).
  * **x64:** Версія для комп'ютерів Mac на базі Intel.
* **Інсталяція:** Відкрийте завантажений DMG-файл та перетягніть **X Minecraft Launcher** у папку **Програми (Applications)**.

:::warning Виправлення блокування macOS Gatekeeper
Оскільки XMCL є відкритим ПЗ і не має дорогого сертифіката розробника Apple, macOS Gatekeeper може заблокувати перший запуск. Виконайте команду в Терміналі:

```bash
# Зняття карантинного атрибута з XMCL
sudo xattr -rd com.apple.quarantine /Applications/X\ Minecraft\ Launcher.app
```
:::

---

### 2. Homebrew Cask
* **Команда:** `brew tap voxelum/xmcl` && `brew install --cask voxelum/xmcl/xmcl`
* **Кому підходить:** Користувачам macOS, які керують програмами через Термінал та Homebrew.

---

## 🐧 Варіанти для Linux

### 1. Flathub / Flatpak (+ Steam Deck) ⭐ *Рекомендовано для Steam Deck та Flatpak дистрибутивів*
* **Принцип роботи:** Контейнеризований пакет з каталогу Flathub.
* **Головні переваги:** Ізольована пісочниця, нативна інтеграція з ігровим режимом Steam Deck (SteamOS) та автоматичні оновлення через центр додатків Discover.
* **Кому підходить:** **Steam Deck**, Fedora Silverblue, Pop!_OS чи будь-яким дистрибутивам з підтримкою Flatpak.

---

### 2. Deb (`x64` / `ARM64`)
* **Підтримувані дистрибутиви:** Debian, Ubuntu, Linux Mint, Pop!_OS, Elementary OS.
* **Інсталяція:** Подвійний клік або команда `sudo apt install ./xmcl.deb`.

---

### 3. RPM (`x64` / `AArch64`)
* **Підтримувані дистрибутиви:** Fedora, RHEL, CentOS, openSUSE.
* **Інсталяція:** Подвійний клік або команда `sudo dnf install ./xmcl.rpm`.

---

### 4. AppImage (`x64` / `ARM64`)
* **Принцип роботи:** Універсальний виконуваний файл, що працює на будь-якому Linux без інсталяції.
* **Інсталяція:** Властивості файлу -> Дозволити виконання як програми (або `chmod +x xmcl.AppImage`) -> Запустити.

---

### 5. Tar.xz (`x64` / `ARM64`)
* **Принцип роботи:** Звичайний стиснутий tar-архів для ручного розпакування.

---

## 📊 Підсумок: Що краще вибрати?

|---|---|---|---|
| **Windows 10/11** | **App Інсталятор** або **AppX** | **Zip (x64)** | `winget install CI010.XMinecraftLauncher` |

| **Linux (Fedora/RHEL)** | **RPM (x64)** | **AppImage** | — |

## 📂 Додаток: Вибір директорії даних гри

Під час першого запуску XMCL попросить вибрати **Директорію даних гри**. У цій папці зберігатимуться завантажені ресурси, модпаки, версії Java та інстанси.

:::warning Важливо про структуру даних
Не вибирайте стандартну папку `.minecraft` у якості директорії даних XMCL. Створіть нову окрему папку (наприклад, `D:\XMCLData` або `~/XMCLData`).
:::

Детальніше у [Посібнику з керування даними](/uk/guide/manage.md).
