# Гайд по Minecraft Bedrock Edition

X Minecraft Launcher (XMCL) підтримує керування, завантаження та запуск **Minecraft Bedrock Edition** (також відомої як *Windows 10/11 Edition* або *UWP Edition*).

Цей гайд розповідає, як налаштувати Bedrock Edition у XMCL, звідки завантажуються файли та про сумісність з операційними системами.

---

## 1. Системні вимоги та налаштування (Тільки для Windows)

Minecraft Bedrock Edition використовує архітектуру пакетів Windows UWP (Universal Windows Platform) (`Microsoft.MinecraftUWP`).

### Крок 1: Увімкніть Режим розробника Windows
Щоб XMCL міг переключатися між версіями Bedrock та реєструвати розпаковані пакети у системі без щоразового завантаження з Microsoft Store:

1. Натисніть `Win + I`, щоб відкрити **Налаштування Windows**.
2. Перейдіть до **Конфіденційність і безпека** (або *Система*) -> **Для розробників**.
3. Увімкніть перемикач **Режим розробника** (Developer Mode) в стан **Увімкн.**.
4. Підтвердіть запит Windows.

:::warning Вимога ліцензії Microsoft
Ви повинні мати діючу ліцензію на **Minecraft Bedrock Edition** у своєму обліковому записі Microsoft (або завантажити Bedrock з Microsoft Store) для гри в повні релізні версії. Бета/Preview версії вимагають облікового запису з підпискою на програму Insider Beta.
:::

---

## 2. Встановлення та запуск версій Bedrock у XMCL

1. Відкрийте **X Minecraft Launcher**.
2. Натисніть **Створити екземпляр** або відкрийте **Налаштування екземпляра**.
3. Змініть тип/видання гри на **Bedrock Edition**.
4. У селекторі версій оберіть потрібний реліз, бету або Preview-збірку.
5. Натисніть **Встановити**. XMCL завантажить пакет версії та розпакує його у вашу папку даних.
6. Натисніть **Запустити**. XMCL автоматично зареєструє версію у службі Windows AppX та запустить гру.

---

## 3. Звідки беруться пакети Bedrock?

Усі файли версій та метадані Bedrock отримуються безпосередньо з офіційної інфраструктури:

- **База даних версій (`mrarm.io/r/w10-vdb`)**: Надає індексований список GUID (Update Identities) для публічних релізів та preview-версій.
- **Завантаження пакетів (`tlu.dl.delivery.mp.microsoft.com`)**: Файли пакетів (`.appx`) завантажуються напряму з **офіційного CDN оновлень Microsoft (Windows Update Delivery)**. XMCL не зберігає і не розповсюджує файли гри.

---

## 4. Сумісність з операційними системами (Windows vs macOS vs Linux)

| Операційна система | Стан сумісності | Деталі |
| :--- | :--- | :--- |
| 💻 **Windows 10 / 11** | ✅ **Повна підтримка** | Нативне UWP середовище. Переключення версій та запуск працюють бездоганно. |
| 🍎 **macOS** | ❌ **Не підтримується** | Bedrock у XMCL покладається на системні Windows UWP API (`Get-AppxPackage`). На macOS грайте у **Java Edition** або використовуйте сторонні Android-емулятори поза XMCL. |
| 🐧 **Linux** | ❌ **Не підтримується** | Керування пакетами UWP є ексклюзивом Windows. На Linux грайте у **Java Edition** або використовуйте сторонні інструменти (наприклад, `mcpelauncher` для Android APK) поза XMCL. |

:::info Гра на macOS та Linux
Якщо ви користуєтеся macOS або Linux, ми наполегливо рекомендуємо грати у **Minecraft Java Edition** у XMCL — вона на 100% кросплатформенна, підтримує тисячі модів, шейдери та спільну гру на серверах!
:::
