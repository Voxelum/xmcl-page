# Вирішення проблем із запуском та збоями

::: tip ЦЕНТР ДІАГНОСТИКИ ТА ЗБОЇВ
Цей розділ поділено на три спеціалізовані посібники для швидкого вирішення проблем:
- **[Вирішення проблем із запуском та збоями](./troubleshooting.md)** (ви тут) - помилки Java, виділення пам'яті, драйвери відеокарти та конфлікти модів.
- **[Журнали збоїв та коди виходу](./crash-logs.md)** - де знаходяться логи (`crash-reports`, `latest.log`), розшифровка кодів (0xC0000005, 1, 137) і аналіз стектрейсу.
- **[Діагностичний звіт (.zip) та приватність](./diagnostic-report.md)** - як експортувати звіт, що він збирає, повна конфіденційність (відсутність токенів та паролів).
:::

Якщо Minecraft або XMCL не запускаються, зависають або аварійно завершують роботу, більшість проблем пов'язані з несумісними версіями Java JDK, застарілими відеодрайверами, недостатньою кількістю оперативної пам'яті (OOM) або конфліктами модів.

---

## 1. Проблеми з Java Runtime Environment (JRE)

### Неправильна версія Java
Minecraft суворо вимагає відповідності між мажорною версією Java та версією гри:

| Версія Minecraft | Необхідна версія Java | Рекомендований дистрибутив |
| :--- | :--- | :--- |
| **1.20.5+** | **Java 21 LTS** | Eclipse Adoptium Temurin 21 |
| **1.18 – 1.20.4** | **Java 17 LTS** | Eclipse Adoptium Temurin 17 |
| **1.17 – 1.17.1** | **Java 16** | Eclipse Adoptium Temurin 16 |
| **1.16.5 та старіші** | **Java 8 (1.8)** | Eclipse Adoptium Temurin 8 або Zulu 8 |

#### Як виправити в XMCL:
1. Перейдіть у **Налаштування екземпляра** -> **Середовище виконання (Java)**.
2. XMCL автоматично сканує встановлені у вашій системі JDK. Якщо потрібної версії немає, скористайтеся вбудованим завантажувачем: виберіть версію (наприклад, Java 21) і натисніть **Завантажити автоматично**.
3. Не використовуйте 32-розрядну версію Java: вона обмежує пам'ять до ~1.5 ГБ і спричиняє негайні вильоти. Завжди використовуйте **x64** (або **arm64** для Apple Silicon / Raspberry Pi).

---

## 2. Нестача пам'яті та OutOfMemoryError (OOM)

### Симптоми
Гра раптово зависає, лог містить `java.lang.OutOfMemoryError: Java heap space`, або гра вилітає з кодом `1` або `137` (Linux OOM-killer).

### Виправлення:
1. У налаштуваннях екземпляра перейдіть до повзунка **Оперативна пам'ять**:
   - **Ванільний Minecraft / легкі збірки (до 30 модів)**: 3072 МБ – 4096 МБ (3–4 ГБ).
   - **Сучасні великі модпаки (150–300+ модів)**: 6144 МБ – 8192 МБ (6–8 ГБ).
2. **Не виділяйте занадто багато пам'яті**: виділення понад 10–12 ГБ може спричинити довгі мікрофризи через збирач сміття Java (Garbage Collection). Залиште щонайменше 2–4 ГБ вашій операційній системі та графічному процесору.

---

## 3. Графічні драйвери та помилки OpenGL

### Симптоми
Гра падає до відкриття вікна, повідомлення в лозі: `GLFW error 65542: WGL: The driver does not appear to support OpenGL` або виліт бібліотек `nvoglv64.dll` / `amdope64.dll`.

### Виправлення:
- **Оновіть драйвери GPU**: встановіть найновіші версії драйверів безпосередньо від NVIDIA, AMD або Intel (драйвери від Windows Update часто містять лише базові заглушки без повної підтримки OpenGL).
- **Ноутбуки з двома відеокартами**: відкрийте *Параметри Windows -> Дисплей -> Графіка*, знайдіть шлях до вашого `javaw.exe` і встановіть режим **Висока продуктивність** (дискретний графічний процесор).

---

## 4. Конфлікти модів та несумісність завантажувачів

### Симптоми
Повідомлення `Incompatible mod set found!`, відсутні залежності або збої під час ініціалізації класів FML/Fabric.

### Виправлення:
1. **Перевірте версії модів**: моди Fabric не працюють на Forge, і навпаки. Переконайтеся, що всі завантажені `.jar` файли відповідають поточному лоадеру та мажорній версії гри.
2. **Обов'язковий Fabric API**: якщо ви граєте на Fabric, обов'язково встановіть мод `Fabric API`, оскільки переважна більшість модів потребують його як бібліотеку.
3. **Метод бісекції (пошук методом поділу навпіл)**:
   - Вимкніть половину модів у списку екземпляра в XMCL.
   - Запустіть гру. Якщо помилка зникла, винуватець знаходиться у відключеній половині.
   - Повторюйте розподіл, доки не знайдете конкретний конфліктний мод.

---

## 5. Пошкоджені кеші та очищення ресурсів

Якщо гра раптово перестала запускатися без зміни списку модів:
1. У налаштуваннях екземпляра XMCL натисніть **Відкрити директорію екземпляра**.
2. Безпечно видаліть тимчасові папки:
   - `.cache/`
   - `config/` (якщо налаштування моду були пошкоджені, зробіть перед цим резервну копію)
3. У головних налаштуваннях XMCL -> **Сховище** можна запустити перевірку цілісності спільних бібліотек та ванільних асетів Minecraft.
