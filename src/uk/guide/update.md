# Посібник з оновлення

Цей посібник описує способи оновлення XMCL на Windows, macOS та Linux, а також пояснює, як гарантувати збереження всіх ігрових інстансів, збережень світів та облікових записів.

:::tip Гарантія збереження даних
Оновлення XMCL **ніколи не видаляє ваші інстанси, моди, світи чи збережені акаунти**. Усі дані користувача зберігаються окремо від виконуваних файлів лаунчера у захищених системних каталогах.
:::

---

## Windows

### 1. Вбудоване автоматичне оновлення (Стандартний спосіб)
1. Коли виходить новий реліз, у верхній панелі заголовка вікна з'являється індикатор оновлення.
2. Натисніть на сповіщення, щоб переглянути список змін і розпочати фонове завантаження.
3. Після завершення завантаження натисніть **Перезапустити та оновити**. Лаунчер перезапуститься вже у новій версії.

### 2. Пакети AppInstaller та APPX
- Якщо XMCL було встановлено через пакет `xmcl.appinstaller`, операційна система Windows автоматично перевіряє та завантажує оновлення під час запуску програми через службу Windows Delivery Optimization.
- Завантажуються лише інкрементні блоки (змінені файли), що значно заощаджує інтернет-трафік.
- Якщо автоматичне оновлення видає збій, завантажте свіжий файл `xmcl.appinstaller` з офіційного сайту та запустіть його вручну для виправлення.

### 3. Портативний архів (Portable ZIP) та DeskGap
- **Portable ZIP**: Завантажте свіжий архів `xmcl-*-win32-x64.zip` зі сторінки релізів, розпакуйте його та замініть старі файли. Усі ваші світи та налаштування збережуться, оскільки вони зберігаються окремо в `%AppData%\xmcl`.
- **DeskGap (v0.72.0+)**: Розпакуйте новий архів `xmcl-*-deskgap-win32-x64.zip` поверх поточної папки.

## macOS

### 1. Автоматичне оновлення в додатку
- Лаунчер самостійно перевіряє офіційний канал релізів для macOS.
- При появі нової версії завантаження та перезапуск виконуються в один клік.

### 2. Оновлення через файл DMG
1. Завантажте свіжий `.dmg` для процесора вашого Mac:
   - **Apple Silicon (M1 / M2 / M3 / M4)**: `arm64.dmg`
   - **Процесори Intel**: `x64.dmg`
2. Відкрийте файл `.dmg`.
3. Перетягніть **XMCL.app** у папку **Програми (Applications)** та оберіть **Замінити (Replace)**.

:::warning Зняття карантину Gatekeeper
Якщо macOS блокує оновлену програму попередженням про пошкоджений файл або невідомого розробника, виконайте таку команду в **Terminal**:

```sh
sudo xattr -cr /Applications/XMCL.app
```
:::

## Linux та Steam Deck

### 1. AppImage
- **Пряма заміна файлу**: Завантажте свіжий `xmcl-*.AppImage`, надайте йому права на виконання та запустіть:
  ```sh
  chmod +x xmcl-*.AppImage
  ./xmcl-*.AppImage
  ```
- **AppImageUpdate**: Якщо ви використовуєте утиліти автоматизації, лаунчер підтримує бінарне дельта-оновлення через `appimageupdatetool`.
- **Steam Deck**: У режимі робочого столу SteamOS Desktop Mode просто замініть існуючий файл `xmcl.AppImage` у вашій папці `Applications` або `Games`.

### 2. Flatpak (Flathub) — Рекомендовано
Flatpak є офіційно підтримуваним основним форматом для Linux (включно з Arch Linux, Fedora, Ubuntu та SteamOS). Оновіть його через системний центр програм або командою в консолі:

```sh
flatpak update app.xmcl.XMCL
```

### 3. Автономні архіви та бінарні пакети
Для пакетів `.tar.xz`, `.deb` або `.rpm` завантажте останню версію зі сторінки релізів та встановіть поверх поточної.

## Резервне копіювання та шляхи до даних

Якщо перед оновленням ви бажаєте зробити резервну копію вручну, ваші дані зберігаються в таких каталогах:

::: code-group
```cmd [Windows]
%AppData%\xmcl
```
```sh [macOS]
~/Library/Application Support/xmcl
```
```sh [Linux]
~/.config/xmcl
```
:::

Достатньо просто скопіювати цю папку на зовнішній накопичувач або у хмару, щоб отримати повний бекап усіх інстансів, акаунтів та налаштувань.
