Ми раді оголосити про вихід **[XMCL v0.66.2](https://github.com/Voxelum/x-minecraft-launcher/releases/tag/v0.66.2)**! Це оновлення стабільності містить важливі виправлення для системи акаунтів, авторизації Microsoft, передачі файлів у P2P мультиплеєрі та імпорту модів перетягуванням (drag-and-drop), а також масштабні вдосконалення веб-інфраструктури та сервісної платформи Together.

## 1. Покращення системи акаунтів та автентифікації

Після глибокої переробки підсистем акаунтів та ідентичності, версія v0.66.2 усуває граничні помилки та покращує стабільність входу для всіх провайдерів:

- **Оновлення ідентичностей після входу**: Стан акаунтів та сесій тепер оновлюється миттєво після успішного завершення авторизації ([`4a798f4`](https://github.com/Voxelum/x-minecraft-launcher/commit/4a798f45b4e5c4b691f9d97467c3a72a427c1567)).
- **Пряма автентифікація з панелі акаунтів**: Тепер можна запускати процес авторизації провайдерів безпосередньо всередині панелі акаунтів лаунчера ([`4afbab8`](https://github.com/Voxelum/x-minecraft-launcher/commit/4afbab87ebbdef7d9fbaa13c3790fc9887ec2286)).
- **Зрозумілі повідомлення про відсутність профілю Minecraft**: При вході через обліковий запис Microsoft, де ще не куплено або не створено профіль Minecraft Java Edition, лаунчер тепер повертає зрозуміле повідомлення про помилку замість сирого стеку викликів API ([`fd2c0d1`](https://github.com/Voxelum/x-minecraft-launcher/commit/fd2c0d1f846d1e5f75f438a4e54c5b7e12866ec2)).
- **Трасування входу та пасивне тихе оновлення токенів**: Покращено діагностику сесій Microsoft OAuth, а фонове оновлення токенів переведено у пасивний, неблокуючий режим ([`f616c6f`](https://github.com/Voxelum/x-minecraft-launcher/commit/f616c6f7dfe696a8d0fb0125081e597ee4dcfb1d)).

## 2. P2P Мультиплеєр: Кодування імен спільних файлів

Вбудований у XMCL Peer-to-Peer мультиплеєр дозволяє друзям підключатися до локальних світів через зашифровані канали WebRTC DataChannels без потреби у відкритті портів чи Hamachi. У v0.66.2 вирішено проблему, коли пакети ресурсів, моди або файли світу з Unicode-символами або спеціальними знаками в назві могли некоректно передаватися:

- **Кодування заголовків імен файлів**: Відповіді на запити передачі файлів у P2P-каналах тепер суворо кодують імена файлів ([`bf9bf56`](https://github.com/Voxelum/x-minecraft-launcher/commit/bf9bf56da4a6d63cca309370584e98b2f245adbe)), гарантуючи безперебійну синхронізацію ресурсів для будь-яких мовних назв.

---

## 3. Надійний імпорт файлів через перетягування (Drag-and-Drop)

Імпорт `.jar` модів, модпаків (`.mrpack`, CurseForge `.zip`), текстур-паків та збережень світів простим перетягуванням у вікно — одна з найзручніших функцій XMCL.

- **Визначення шляхів через Electron Preload**: Виправлено несумісність визначення шляхів у сучасних версіях Chromium/Electron шляхом безпечного отримання шляхів через preload-міст ([`8c002ee`](https://github.com/Voxelum/x-minecraft-launcher/commit/8c002ee8cf35ca5738d777859a5d8a91cf2d014d)).

## 4. Оновлення веб-платформи та сервісів Together

Паралельно з оновленням лаунчера головний розробник **CI010** впровадив масштабні покращення для офіційного сайту та хмарної платформи (`xmcl-page`):

| Напрямок | Покращення | Результат |
| :--- | :--- | :--- |
| **OAuth Маршрутизація** | Збереження обраної локалі | Після проходження OAuth користувач автоматично повертається на сторінку своєю мовою. |
| **Панель Адміністратора** | Реавтентифікація та сесії | Додано захищену повторну авторизацію, оновлення сесій та прямий редирект до консолі. |
| **Гідрація сесій** | Детермінована гідрація теми | Усунуто розбіжності між SSR та CSR для компонентів VitePress та планів підписки. |
| **Сервіси Together** | Типобезпека білінгу | Посилено безпеку типів для білінгу, оптимізовано процес оплати та оновлено політику відповідності. |
