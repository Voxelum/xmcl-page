## 🌟 1. Повноцінна система резервного копіювання та фоновий авто-бекап (Backup & Restore)

Безпека збережень та налаштувань ваших світів Minecraft — один із найвищих пріоритетів. У версії 0.73.0 реалізовано комплексну підсистему створення резервних копій та відновлення ([PR #1815](https://github.com/Voxelum/x-minecraft-launcher/pull/1815)).

![Діалог резервного копіювання XMCL](https://github.com/user-attachments/assets/b110bf62-102e-4e03-97d0-556689211184)

### Основні можливості резервного копіювання:
* **Портативні архіви в один файл (`.xmclbackup` / `.zip`)**:
  * Створення повного архіву налаштувань лаунчера (`setting.json`), збережених колекцій (`collections.json`), кастомних тем і графічних ресурсів (`theme.json`, `theme.css`, `theme-media/`), а також вибраних Java-інстансів.
  * **Розумна фільтрація**: лаунчер автоматично виключає спільні бібліотеки завантажувачів, кеш ванільних ассетів Minecraft та тимчасові логи. Завдяки цьому архіви залишаються компактними, створюються за лічені секунди й не дублюють гігабайти спільних даних.
  * **Два режими збереження модів**:
    1. *Повні файли (`.jar`)* — повна автономна копія інстансу.
    2. *Легкий список модів (`mods-list.json`)* — ультра-легкий файл, який зберігає лише метадані та хеші, завантажуючи файли автоматично при відновленні.
* **Детальний моніторинг операцій**:
  * Відображення прогресу в реальному часі, лічильники оброблених категорій, оцінка витраченого та залишкового часу й докладний системний журнал активності.
* **Гнучке вирішення конфліктів при відновленні**:
  * Якщо екземпляр із такою назвою вже існує, ви можете обрати: **Перейменувати (Rename)**, **Перезаписати (Overwrite)** або **Пропустити (Skip)**.

### Фоновий авто-бекап (Background Auto-Backup):
* **За замовчуванням вимкнений** для збереження ресурсів.
* Підтримує вибір одного або декількох Java-інстансів (з автоматичним виключенням Bedrock).
* **Гнучкий розклад**: автоматичне спрацьовування кожні 30 хвилин, 1, 2, 6, 12 або 24 години.
* **Автоматична ротація архівів (`maxBackups`)**: запобігає переповненню дискового простору, самостійно видаляючи найстаріші копії.
* **Фільтри вмісту**: вибір окремих компонентів для архівування (світи/збереження, конфіги, моди, ресурспаки, шейдери, налаштування).
* Кнопка **«Запустити зараз» (Run Now)** для швидкого створення знімка перед ризикованим оновленням гри, а також журнал останніх копій із кнопками швидкого відновлення, перегляду у файловому менеджері та видалення.

## 📸 2. Менеджер скріншотів із безпечним редактором (Screenshot Manager)

Відтепер керувати пам'ятними моментами з гри можна прямо в лаунчері завдяки новому вбудованому менеджеру скріншотів ([PR #1803](https://github.com/Voxelum/x-minecraft-launcher/pull/1803), [PR #1824](https://github.com/Voxelum/x-minecraft-launcher/pull/1824)).

### Можливості:
* **Зручна галерея знімків**: переглядайте скріншоти конкретного профілю або всіх інстансів у вигляді адаптивної сітки з датами створення та розмірами.
* **Повноекранний лайтбокс**: перегляд у рідній роздільній здатності зі зручним масштабуванням і перемиканням клавішами стрілок.
* **Швидкі файлові операції**:
  * Копіювання зображення або файлу прямо в буфер обміну.
  * Безпечне перейменування та видалення з діалогом підтвердження.
  * Відкриття розташування файлу в системному провіднику (Explorer, Finder або Nautilus).
* **Інтегрований редактор зображень**:
  * Швидке кадрування (crop), додавання підписів, стрілочок і виділень перед тим, як поділитися скріншотом із друзями чи на Discord.
* **Зручна діалогова інтеграція**: менеджер відкривається як плаваюче діалогове вікно без скидання поточної сторінки та зберігає фокус вводу й drag-and-drop.

## 🛒 3. Новий сучасний інтерфейс ринку модів (Mod Market Redesign)

Ринок модів та контенту спільноти отримав значне візуальне та архітектурне оновлення ([PR #1805](https://github.com/Voxelum/x-minecraft-launcher/pull/1805)):

* **Сучасний дизайн карток**: оновлена типографіка, зручні бейджі авторів, підтримуваних завантажувачів та кількості завантажень на платформах Modrinth і CurseForge.
* **Збереження стану пошуку (Search State Preservation)**:
  * Раніше при переході на сторінку деталей проекту та поверненні назад пошуковий запит чи вибрані фільтри могли скидатися. Тепер стан вводу, активні категорії, сортування та положення прокрутки зберігаються бездоганно.
* **Миттєва фільтрація**: швидкі перемикачі завантажувачів (Forge, Fabric, Quilt, NeoForge), версій Minecraft та середовища виконання (Client / Server).

## ⚡ 4. Швидкий перемикач акаунтів у бічному меню (Quick Account Switcher)

Для гравців, які використовують декілька облікових записів або чергують ліцензійний Microsoft-акаунт з іншими сервісами, додано блискавичне контекстне меню ([PR #1808](https://github.com/Voxelum/x-minecraft-launcher/pull/1808)):

* Клік правою кнопкою миші на аватарці користувача в бічній панелі викликає компактне спливаюче меню.
* Дозволяє миттєво вибрати інший збережений акаунт (Microsoft, Offline, Ely.by, LittleSkin) без необхідності відкривати повні налаштування акаунтів.
* Поточний активний профіль позначено галочкою, а внизу доступний пункт швидкого додавання нового профілю.

## 📦 5. Валідований експорт Packwiz та покращення Modpack Builder

Розробники та творці збірок отримали потужний інструмент експорту ([PR #1804](https://github.com/Voxelum/x-minecraft-launcher/pull/1804)):

* **Підтримка формату Packwiz**: генерація коректних маніфестів `pack.toml` та індексних списків `index.toml` із контрольними хешами файлів. Формат Packwiz ідеально підходить для ведення збірок через Git та легких оновлень клієнтів.
* **Вдосконалений білдер збірок**: покращено інтерфейс вибору включених файлів, конфігурацій, оверрайдів та текстурпаків при підготовці архівів для CurseForge та Modrinth.

## 🛠️ 6. Виправлення помилок, підвищення стабільності та оптимізації

Окрім нових можливостей, випуск 0.73.0 містить низку важливих технічних виправлень ядра лаунчера:

* **Полірування діалогів скріншотів (#1824)**: виправлено відступи панелей інструментів, прибрано зайві закруглення кутів у повноекранному режимі лайтбокса та повністю перекладено всі повідомлення китайською та іншими мовами.
* **Захист телеметрії та зворотного зв'язку (#1817)**: додано запобіжники проти збоїв під час надсилання репортів та виправлено помилки збору діагностики.
* **Публічні імпорти ядра (`@xmcl/installer`) (#1809)**: виправлено проблему завантаження пакетів інсталятора сторонніми споживачами за межами робочого простору монорепозиторію.
* **Точний підбір середовища Java (#1813, `ecc13691`)**: лаунчер тепер автоматично встановлює та обирає саме ту версію Java (наприклад, Java 17 чи 21), яку вимагає запрошений завантажувач або версія Minecraft при натисканні кнопки «Встановити».
* **Оптимізація AI-агента (#1812)**: припинено глибоке спостереження за повним транскриптом чату штучного інтелекту, що усунуло стрибки навантаження на процесор та затримки рендерингу інтерфейсу.
* **Сумісність середовища DeskGap / Electron (`b64e90f6`)**: додано поліфіли для idle-callback функцій та відкрито доступ до системних оновлень платформи.
* **Очищення стану авторизації (`029f9ba4`)**: тепер застарілі помилки входу очищаються відразу при зміні джерела автентифікації.
* **Непомітне визначення Java у Windows (`e43edcbe`)**: приховано миготливі чорні консольні вікна перевірки версії Java у фоні та налагоджено прийняття зворотних редиректів Microsoft OAuth loopback.
