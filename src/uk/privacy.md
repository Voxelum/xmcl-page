# Повідомлення про приватність відкритого проєкту XMCL

**Дата набрання чинності: 14 серпня 2026 р. · Версія: OP1-2026-08-14**

Це повідомлення стосується публічного сайту XMCL і безкоштовного лаунчера з відкритим кодом. Воно не поширюється на облікові записи, платежі, ШІ, сигналінг, TURN та інші додаткові сервіси XMCL Together; для них діє [Політика конфіденційності XMCL Together](./together/privacy).

Сайт використовує Microsoft Azure Application Insights для збору відомостей про перегляди, вибір завантажень, приблизні параметри мережі й пристрою, браузер і діагностичні події. Також зберігається cookie з мовними налаштуваннями.

Лаунчер може надсилати випадковий ідентифікатор інсталяції або пристрою, події запуску й завершення гри, відомості про сервіс входу, параметри запуску, коди завершення, версію застосунку, дані операційної системи та неочікувані помилки зі стеком. Діагностика іноді може містити шляхи до файлів, назви збірок і користувачів, адреси серверів або значення з конфігурації.

Ці відомості використовуються для доставки завантажень, діагностики, безпеки та покращення XMCL. Їх можуть обробляти Microsoft Azure, Vercel, GitHub і супровідники проєкту, яким потрібен доступ для підтримки, надійності або безпеки. Ми не продаємо персональні дані й не використовуємо телеметрію лаунчера для міжконтекстної поведінкової реклами.

Вимикайте необов'язкову телеметрію там, де доступне відповідне налаштування, і перевіряйте журнали перед публікацією. Із запитами про доступ, виправлення або видалення допустимих непублічних даних звертайтеся до CI010: **cijhn@hotmail.com**. XMCL не призначений для дітей молодше 13 років.

XMCL — незалежний проєкт із відкритим кодом, не пов'язаний із Microsoft або Mojang Studios і не схвалений ними.
